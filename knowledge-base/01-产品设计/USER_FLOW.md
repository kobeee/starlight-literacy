**学习循环（核心）**：

> 🔴 **2026-05-29 教学法重审修订**：学一个字的主路径改为「认读绑定（图音字）→ 动手指认（真看图认字）→ 跟读 → 写 → 复现」五步；**字源从"每字必经的开场讲解"降级为"仅象形字的收尾彩蛋"**。下方旧图保留作历史对照，权威序列以 [[幼龄儿童认字教学法重审与学字新流程]] §3 为准。

```
进入单元 (P02)
  │
  ▼
┌───── 循环 N 个字（2026-05-29 修订后） ───────────────────────┐
│  认读绑定(图音字) → 动手指认 → 跟读 → 写 → 复现             │
│  象形字才在认读后追加「字源彩蛋」(实物→甲骨→今字形变)        │
└──┬─────────────────────────────────────────────────────────┘
```

旧序列（已被上方修订取代，留作对照）：

```
┌───── 循环 N 个字 ─────────────────┐
│  P03 认  →  P04 写  →  P05 练     │
│  (单字 5~10s 速练，错也过)         │
└──┬───────────────────────────────┘
   │ 一组字（≈5字）学完
   ▼
P06 小组练习 (2~3题，听音/看图/拖拽)
   │
   ├── 还有下一组 ──→ 回到 P03 学新字
   │
   └── 全单元字学完
          ▼
       P07 单元测验 (8~10题综合)
          │
          ▼
       P08 测验结果
          │
       ┌──┴──┐
       ▼     ▼
     通过   未通过
       │     │
       │     └──→ "再试一次" → 回 P07
       │
       ├──→ 解锁下一单元 → 回 P01
       └──→ 进入 Unit-02 时若未付费 → P09 付费引导
```

**过关庆祝（P07-celeb）**：每个字"练"完成 → 触发庆祝小弹层/页（**注意：当前设计稿"P07-过关庆祝页"是单字过关，与PRD"P07单元测验"编号冲突，详见偏离清单**）。

## 2. 按钮去向表（每页每按钮的跳转）

> 🔴 **2026-05-30 iOS 原生链路（教学法重审后）**：iOS 原生 App 的学一个字主路径**与下方 H5 旧表顺序不同**，权威顺序为 `认读绑定 → [象形字源彩蛋] → 看图认字 → 跟读 → 写（=完成）→ 复现`。各 CTA 去向（`AppModel` 路由）：
>
> | iOS 页面 | CTA | 去向（route） |
> |---|---|---|
> | P01 旅程卡 / P02 开始 | 点亮第一颗星 / 继续学 / 开始第一字 | `startUnit()` → `.recognize(currentCharId)` |
> | P03 认读绑定 | 认识它啦 → | `markRecognized` → `routeAfterRecognize`（象形→`.etymology`，否则→`.imageCard`） |
> | 字源彩蛋（仅象形） | 去认一认 → | `routeAfterEtymology` → `.imageCard` |
> | P05 看图认字 | 点出正确项后→去跟读 | `markIdentified(stars)` → `routeAfterImageCard` → `.followRead` |
> | P05a 跟读 | 去写一写 → | `markFollowed` → `routeAfterFollow` → `.writing` |
> | P04 写字（完成步） | 下一字 / 本单元学完去复习 | `markWritten` → `routeAfterWriting`（有下一字→`.recognize`，否则→`.group`）；首次通过登记复习曲线起点 `passedAt/reviewStage=0/lastReviewAt` |
> | P01 今日复习卡（到期才出现） | 去复习 | `model.go(.review)`（**不过家长门**，复习是孩子学习内容）|
> | P12 间隔复习关 | 认对 → 下一字 / 全认完 → 回地图 | 认对 `recordReview`（推进遗忘曲线档位）→ `idx+1`；末字 → 完成态 → `.map` |
>
> **P12 间隔复习关（2026-06-03 第四刀新增 · route `.review`）**：教学法五步法第 5 步「复现」的「时间维度」面——P06 小组练习已覆盖「本课结尾即时再认」，P12 补「按艾宾浩斯遗忘曲线（1/2/4/7/15 天）隔天/隔几天再认前面学过的字」。交互复用看图认字（图+念音→纯汉字候选认形）；到期判定 `ReviewSchedule`（纯函数）；入口在 P01（`dueReviewIDs` 非空才出现）；留存证据亮给家长（P11「学习留存」卡）。**不做本地推送**（用户拍板 C，留二阶段）。
>
> 不可绕过性由模型层顺序门保证（`markX` 各守上一步），非 UI 置灰；7 条 `MoatGateTests` 守护。下方 H5 旧表保留作历史对照。
