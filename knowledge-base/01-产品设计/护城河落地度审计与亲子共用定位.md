# 护城河落地度审计 + 亲子共用定位拍板（2026-06-03）

> 背景：上个 session 走查出四母题（界面假设识字大人在场、孩子自己走不通）。本 session 先讨论解法 → 用户两次点破「你在自己知识库里 YY」要求上网查 2026 最佳实践（见 [[2026幼龄识字与跟读最佳实践调研]]）→ 用户抛出真正的根本问题：**「护城河只停留在文字上，没落实到 APP」**→ 当场对 iOS 代码逐页审计。**本 session 零代码修复，全部改动仍未 commit。**

## 一、定位拍板：从「孩子自驱」改为「亲子共用」

用户原话：「**如果没法做到孩子自用，那就亲子共用，既然有亲子，那就做得更加和谐一些，要足够能吸引孩子、激发孩子的学习欲望，同时不能太唬弄家长**。」

**三目标（定位级，写进项目约束）**：
1. **吸引孩子 / 激发学习欲望**（孩子层）
2. **不唬弄家长**（家长层）—— 家长是付费决策者 + 在场陪伴者
3. **亲子之间和谐**（配合顺畅，不互相别扭）

**关键解套**：接受「亲子共用」后，**「去文字化」不再是铁律**。因为有识字家长在场，界面可做成**双层**——
- **孩子层**：图 / 音 / 互动 / 即时正反馈 / 成就感；
- **家长层**：文字 / 字源依据 / 进度 / 判定结果。

> 上个 session 的问题二（「按住说话」5 岁不懂）、问题三（手指引导丑）本质都是「既要孩子全自驱、又不能用文字」憋出来的死角。**亲子共用一确认，这个死角消失**——很多设计前提要据此重想，但不要推翻已做对的东西（避免钟摆，见 [[feedback_pendulum_modification]]）。

## 三、核心洞察：护城河分两层，能力层大半做了，感知层几乎全空

把 6 条拆两层看，「护城河只停留在文字上」就精确了：

- **能力层（代码到底做没做）**：6 条里 **4 条真做了**（写字、字源内容、付费、克制），**1 条做反**（跟读），**1 条纯文案**（规模）。写字判定和付费透明这两条，**代码扎实得对得起「护城河」三个字**。

- **感知层（亲子共用时家长能不能摸到、能不能验证）→ 几乎为零**：
  - 写字真判定：**默默判**，家长不知道它真在拒乱画；
  - 字源真讲：真象形依据**藏在一句话里**，且**承诺的「家长可回看验证」是空的**；
  - 付费透明：做得最好，但**得孩子帮忙翻到付费 tab 才看得到**；
  - 规模 / 克制：一个数字、一个沉默，**体验里摸不到**。

> **「护城河只停留在文字上」的精确含义**：它们停留在**代码能力和文档主张**里，没有变成**亲子共用时家长能当场摸到、当场验证、当场信服「这值 199、不像洪恩唬人」的体验**。而护城河真正的受众——付费的家长——恰恰是亲子场景里就坐在旁边那个人。
>
> 方法论沉淀见 [[feedback_moat_capability_vs_perception]]。

## 四、最扎心的三条（按严重度）

1. 🔴 **跟读是负资产**——不是没做护城河，是把护城河做反成了欺诈，踩穿立项初心。**得先止血。**（核心矛盾见 [[跟读真纠音与零挫败的矛盾]]，结论已校准：本阶段不判分 / 出声门 / A/B 对听 / 出声给星，ASR 评测进二阶段）
2. 🔴 **字源「家长可验证真象形」是写在注释里的空头支票**——P11 没入口。「文字护城河」最典型的标本：话说了，东西没建。
3. 🟡 **写字 + 付费这两条真本事，埋着没让家长看见**——最可惜，东西是好的，差一个「亮出来给家长」的动作。

## 五、下个 session 处置顺序（建议，未拍板细节）

> 范围仍只 Unit-01。主线从「修四母题的工艺」升级为「**护城河可感知化** + 亲子共用双层重构」。

1. **止血跟读（护城河 2）**：删假判分文案 + 出声硬门 + A/B 对听 + 出声给星（详见 [[跟读真纠音与零挫败的矛盾]]）。
2. **把已做好的能力「亮给家长」（护城河 1/3/6 的感知层）**：
   - 写字：判定结果做成家长看得到的「真判了笔顺」反馈；
   - 字源：补家长中心字源回看入口（兑现注释承诺）+ 4 段叙事用起来 + 强化「图变字」演化；
   - 付费：透明承诺主动呈现给家长，不靠孩子翻 tab。
3. **补家长门（母题 C）**：付费 / 家长中心加家长验证门，营销搬出 P08 学习流终点。
4. **2026 调研里可借鉴的主路径级动作**（见 [[2026幼龄识字与跟读最佳实践调研]]）：音→形绑定（Duolingo ABC 读音高亮字形）、艾宾浩斯间隔复习填「复现」空环、每课新字 0–3 个重切节奏。**这几条触教学法主路径，动手前回读 [[幼龄儿童认字教学法重审与学字新流程]] 防钟摆。**

> 诚实边界（[[feedback_function_pass_not_product_pass]]）：以上都是 AI 的设计推断，「孩子学没学会、想不想继续」仍只有真孩子能验——但用户本 session 明确「**先别管真孩子测不测**」，先把护城河落地到 APP。
