## 3. 知乎深度测评 · 头部家长共识（信号权威度最高）

> 来源：多篇知乎专栏头部测评，写作家长普遍跑过 6 个月以上完整周期。
> 完整链接见 §10 参考资料。

### 3.1 学习效果质疑（高频）

> 「孩子只记住了游戏，没记住该学的知识」
> 「认 / 练 部分学习内容薄，有些练习不需要孩子动脑」
> 「缺少跟读纠音环节，孩子发音可能不准」

### 3.2 「直映认字法」被批（独家深度信号）

> 「字解释过于牵强，把不相关的物体硬凑」
> 「只帮孩子记字形，不解释字的本义」

**含义**：洪恩字源讲解是「编故事强行联想」（例如「日 像太阳眼睛」「数字 1 像棍子」），不是真讲字源。**这是高知家长真正反感的设计**，但普通家长感知不到。

**对照星光识字 PRD v3.0 §13.7-§13.8**：
- 「一轮明月悬于水面，倒影形成『一』字线」= **真象形**（方向对了 ✅）
- 这正是我们的差异化护城河

### 3.3 游戏化过度（高频）

> 「游戏使学习软件偏向娱乐化」
> 「孩子需要游戏奖励才学习，未来接受枯燥课堂会困难」
> 「孩子玩游戏不动脑，简单记成游戏体验而非教育内容」

### 3.4 家长支持薄弱

> 「班主任只解决学习问题 + 推销活动，不督学」
> 「家长不投入精力陪同，学习效果无法保证」

### 3.5 退款政策硬伤

> 「退款问题一直是最大问题——无论误买还是不满意，都不支持 7 天无理由退款」

## 6. 反差化机会清单（星光识字 vs 洪恩）

| 维度 | 洪恩现状 | 星光识字方向（PRD v3.0 现有） | 反差化等级 |
|---|---|---|---|
| 付费模型 | 自动续费坑 / 不退 / 推诿 / 永久含糊 | 7 天无理由 + 透明 + 不卖含糊"永久" | 🟢 强反差（最易做到） |
| 游戏化 | 重度 / 上瘾 / 关不掉 | 零挫败但克制 / 游戏可限可关 | 🟢 强反差 |

| 视频精度 | 动画不错但**非买点** | v5-cinematic 合格线即止 | ⚖️ **不投入军备竞赛** |

## 7. 八条产品红线（项目硬约束 · 永不可越）

### 🔴 7.1 付费机制透明 · 不做"误扣""自动续费坑"

**红线**：任何付费弹窗 / 续费 / 取消订阅入口必须做到：
- 价格 / 周期 / 是否自动续费 一屏明示，禁止小字
- 自动续费需 **二次确认**（不能默认勾选）
- 取消订阅入口 ≤ 2 次点击可达
- 不在 P03/P04/P05 等学习页弹付费墙打断学习

**反例**（洪恩踩过的雷）：
> 「悄悄自动续费还不能退钱」
> 「不通知用户，自动扣费」
> 「支付页面没有明确提供自动续费的说明」

---

### 🔴 7.2 退款宽松 · 7 天无理由 + 不卖含糊"永久"

**红线**：
- 提供 **7 天无理由退款**，明示于购买页（行业内是稀缺承诺）
- 客服标准话术中 **禁用** 「虚拟产品不可退款」「这是苹果系统问题」「超过退费时间」
- **禁止**使用「永久」「终生」等模糊承诺。如必须使用，需明确说明：「包含的字数 / 单元 / 不包含的内容」一屏说清
- 若涨价 / 缩水内容，老用户必须保留原承诺

**反例**（洪恩踩过的雷）：
> 「388 元终生套餐只能学 20 个字」
> 「购买了永久版权，现在学不到 1000 个字，又要求购买」
> 「几年前买了 200 字永久版，重新登录查不到记录，需要重新购买」

---

### 🔴 7.3 字源真讲 · 禁止"直映法"牵强联想

**红线**：
- P03 字源插画必须是 **真象形 / 真会意**，不是"编故事强行联想"
- 每个字的字源解释需有 **甲骨文 / 金文 / 篆文** 任一为依据，不能"自由发挥"
- 字源动画 / 文案 必须 **儿童能看懂 + 成人能验证为真实字源**

**正例**（PRD §13.7-§13.8 已落地）：
- 「一 = 一轮明月悬于水面，倒影形成『一』字线」（真象形 ✅）
- 「日 = 太阳的圆轮」（甲骨文真形 ✅）

**反例**（洪恩直映法）：
> 「字解释过于牵强，把不相关的物体硬凑」
> 「只帮孩子记字形，不解释字的本义」

---

### 🔴 7.4 写字真判定 · 拒绝"乱画也判对"

**红线**：
- P04 田字格描红必须做 **真笔顺判定 + 真起笔落笔位置判定**
- "判定通过"的标准必须比洪恩高，至少识别：起笔位置 / 笔顺顺序 / 是否离田字格太远
- "判定不通过"时按 [[01-产品设计/儿童零挫败设计原则|零挫败原则]] 处理：降难度提示，不打击信心
- 不能为了"零挫败"而做"乱画也判对"——那是数据造假，长期伤害家长信任

**反例**（洪恩踩过的雷 · 市场空白机会）：
> 「无法识别孩子写出来的字真实水平，根本就不是让写的字，都是乱画的，还说写的很好」
> 「有些字的笔画有错」

**这是星光识字真正的差异化护城河之一**。

---

### 🔴 7.5 游戏化必须克制 · 可关 / 可限次 / 不喧宾夺主

**红线**：
- 任何"游戏关卡"必须有 **家长控制开关**（隐藏 / 关闭 / 限次）
- 单次"识字 → 游戏奖励"循环时间，**游戏部分 ≤ 识字部分 30%**
- 不引入 **乘法 / 繁体字 / 拼图** 等与识字无关的游戏内容
- [[01-产品设计/儿童零挫败设计原则|永远给星]] 是反馈机制 ≠ 游戏化堆砌。星星可以给，但不能"游戏关一个接一个"

**反例**（洪恩踩过的雷）：
> 「游戏比认字时间还多」
> 「游戏太上瘾了，还是得逐渐摆脱掉，不建议拿来学汉字」
> 「繁体字和乘法根本防不住」
> 「很多游戏不能关闭和隐藏，不利于孩子成长」

---

### 🔴 7.6 跟读纠音必须做 · 不能只放音

**红线**：
- 每个字必须有 **跟读环节**（孩子录音 + 音频对比）
- 跟读反馈走零挫败原则：哪怕完全跟不上也给鼓励 + 重听机会
- 使用现有 [[../05-技术文档/baked-audio-架构]] (XiaoxiaoNeural) 作为标准音

**反例**（知乎深度测评共识）：
> 「缺少跟读纠音环节，孩子发音可能不准」

---

### 🔴 7.7 教材衔接需有教学法依据 · 不能"工具能渲染什么就选什么"

**红线**：
- Unit-01 的 20 字选择 **必须有教学法 + 部编版 / 字频 / 笔画难度依据**
- 不能是"HyperFrames 容易做的字优先"
- 解锁顺序需有教学逻辑（独体→合体 / 横→竖→撇→捺 / 频次高→低）

**反例**（洪恩用户诉求）：
> 「目前孩子上一年级，更希望是按照学校课本顺序来认识生字」（这是付费家长反复提的）

---

### 🔴 7.8 视频精度不打军备竞赛 · v5-cinematic = 合格线

**红线**：
- HyperFrames 视频品质 **以 v5-cinematic (9.12) 为合格线**，不再追求更高
- 任何「再做一版」的请求，AI 必须先 **反射性挑战**：「上一版有什么实证的儿童体验问题？还是只是审美偏好？」
- 用户 ≥ 3 次说「再做一版」时，AI 必须停下来 **重新评估方向**，不能继续无限迭代
- yi-v6 / v7 / v8 / v9 等无功增量的失败迭代作为 **审计样本** 保留，不再继续打磨"一"
- 新字应用 v5 同方法快速跑通，量重于质

**最硬证据**（本次调研得出）：
> 所有 150 条洪恩 ★5 好评里 **没有一条** 夸"动画精美 / 画面惊艳 / 特效炫"
> → 视频精度 **不在家长购买决策因子里**
> → yi-v6→v9 的 13 天迭代是 ROI 负值

详见 [[../../memory/feedback_validator_pass_not_product_pass]] + [[../../memory/feedback_do_not_wait_for_approval]]

---

### 🔴 7.9 邀请机制禁现金 / 禁课程券 / 禁可流通积分（2026-05-26 扩展）

**红线**：
- 任何"邀请奖励"必须是**产品内容权益**（单元解锁 / 学伴券）或**情感符号**（徽章 / 推荐人记录）
- **禁忌**：现金红包 / 课程券（可流通） / 积分（可兑换通用商品） / 无上限激励 / 学习页弹邀请入口
- 邀请入口仅在**家长中心**可见，**不在学习页 / 庆祝页 / 付费页弹出**

**为什么这是红线**：

| 风险维度 | 触雷代价 |
|---|---|
| 微信《小程序运营规范》4.16 | 诱导分享换利益 = 警告 → 限流 → 封号（拼多多砍一刀先例）|
| 红线 §7.5 游戏化克制 | 分享换钱本质是在产品外搞上瘾设计，等同于洪恩焦虑营销 |
| 反差化立场 | 洪恩做分销 → 我们如果也做返现 = 立场归零 |
| 合规与运营成本 | 现金涉个税 / 银行结算 / 风控 / 套现产业链，¥100 收益撑不起 |

**正例**（[[砍cinematic后执行方案]] §3.2 定稿）：
- 被邀请人 = Unit-02 + Unit-03 永久解锁（30 字内容权益）
- 邀请人（未买断）= 1 个未购买单元永久解锁权（上限 10 次累计 ≈ ¥99 等值内容）
- 邀请人（已买断）= 学伴礼物券可转赠（同上限）

**反例**（不可越的雷）：
- ❌ "每邀请 1 人 ¥20 红包" → 触微信 4.16 + 违 §7.5 + 立场归零
- ❌ "邀请 5 人送 99 元课程券" → 课程券可流通，与现金等同
- ❌ "邀请人获得 200 星光值可兑换实物" → 积分可流通，同样违规
- ❌ 学习页弹"邀请好友送 X" → 违 §7.5 "不在学习页打断" 延伸

## 9. 设计评审检查清单（每次评审必走）

任何对客功能 / 页面 / 视觉 / 付费 / 教学逻辑变更前，按此清单逐项检查：

### 付费相关
- [ ] 付费弹窗是否在学习页面打断学习？（应在结算节点 / Unit 边界）
- [ ] 自动续费是否默认勾选？（必须默认不勾）
- [ ] 是否有"永久 / 终生"承诺？如有，承诺范围是否一屏说清？
- [ ] 7 天无理由退款承诺是否在购买页明示？
- [ ] 客服话术是否禁用"虚拟产品不可退款"等推诿模板？

### 游戏化相关
- [ ] 是否有"游戏关卡可关"开关？
- [ ] 单次循环中游戏时间是否 ≤ 识字时间 30%？
- [ ] 是否引入与识字无关的游戏内容（拼图 / 乘法 / 繁体字）？
- [ ] 永远给星是否做成"游戏关一个接一个"？

### 字源 / 教学相关
- [ ] 字源讲解是否真象形 / 真会意？甲骨文 / 金文 / 篆文依据是否能列出？
- [ ] 是否存在"日 像太阳眼睛"这种牵强联想？
- [ ] 选字顺序是否有教学法依据（部编 / 字频 / 笔画难度）？

### 写字相关
- [ ] P04 是否做真笔顺判定？
- [ ] "乱画"是否会被判通过？（如果会，违规）
- [ ] 判定不通过时是否走零挫败降难度？

### 跟读相关
- [ ] 每字是否有跟读环节？
- [ ] 跟读反馈是否走零挫败原则？

### 视频相关
- [ ] 当前迭代相比上一版有什么实证的儿童体验问题，还是审美偏好？
- [ ] 用户是否已说过 ≥ 3 次「再做一版」？如有，必须停下来 review 方向
- [ ] 是否在投入"超过 v5-cinematic 合格线"的精度？

### 邀请机制相关（2026-05-26 扩展）
- [ ] 邀请奖励是否为产品内容权益或情感符号？（不可以是现金 / 课程券 / 积分）
- [ ] 邀请入口是否仅在家长中心可见？（不可以在学习页 / 庆祝页 / 付费页）
- [ ] 邀请奖励是否设置上限（防止变成"邀请副业"）？
- [ ] 是否做了"分享换利益"诱导文案？（违微信《小程序运营规范》4.16）
