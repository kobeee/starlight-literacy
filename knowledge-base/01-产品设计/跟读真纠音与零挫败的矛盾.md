# 跟读「真纠音」与「零挫败」在不接 ASR 下的矛盾

> ~~这是一条**还没解决**的产品级矛盾~~ → **2026-06-03 本阶段方向已定**（用户认）：**App 不假装判音准；删「很像/不太像」假判分；改「出声硬门（没出声→温柔引导再录、不算错）+ 录上了就给星 + 双波形 A/B 对听让耳朵自己判」；真发音评测进二阶段。** 用户原话：「要的是能 A/B 对听，不是 App 必须给『像不像』的判分；小孩不能在准不准上较真，**但绝不允许做假、误导**。」详见 [[护城河落地度审计与亲子共用定位]]。

## 一句话

**不接 ASR 时，跟读只能比「包络形状（cosine）」，而包络形状根本分不清「读对 / 瞎读 / 没读」**——于是三条既有约束在这个前提下两两打架：

| 约束 | 出处 | 它要什么 |
|---|---|---|
| **真纠音·不能哄** | 红线 §7.6 | 没读对 / 没读，就**不能**说「很像真棒」 |
| **零挫败·永远给星不羞辱** | 儿童零挫败设计原则 | 读不好**不能**罚、不能让孩子挫败 |
| **不接 ASR** | 砍cinematic §2.2（科学决策·数据驱动二阶段） | 只能用双波形/包络，拿不到「他到底读了哪个字」 |

- 「真纠音」↔「零挫败」：一个要求"读错要纠"、一个要求"永不罚"，本就有张力（原本靠"柔性提示不降档"调和）。
- 「不接 ASR」把张力放大成**真矛盾**：因为没有 ASR，系统**判不出**对错，于是打分只能在两个坏结局里选——
  - 偏松（当前）：平包络/静音也给高分 → **哄小孩**（踩 §7.6，用户暴怒的就是这个）。
  - 偏紧：随便波形不达标就低分 → **挫败**（踩零挫败）。
- 当前实现（`FollowRecorder.scoreTier`，`cos>0.6` great）落在"偏松"，且**没出声的静音→平包络→cos 偏高→误判 great**，是最坏形态："连读都没读还夸"。

## 已知的几个候选方向（仅备讨论·均未定）

> ⚠️ 别钟摆：bug#2（读对却『再试一次』）↔ 本问题（没读却『真棒』）已经来回一次，下次要从根上定，不要又一个补丁把另一头打翻。

1. **加「有没有在出声」的硬前置门（能量/VAD）**：先判这段录音里**到底有没有人声能量**（不是判读得对不对，只判"有没有出声"）。没出声 → 不给 great、引导"再录一次"（仍不羞辱）；有出声 → 再进 cosine 给鼓励档。**好处**：堵住"没读也夸"这个最丢人的洞，且不需要 ASR、不踩零挫败（没出声不是"读错"是"还没读"）。**疑点**：能量门限怎么定才不误伤小声的孩子；这是补丁还是治本。
2. **重新定位"跟读打分"到底承诺什么**：也许根本不该呈现成"像不像"的判分，而是"录到了 → 回放对比，让孩子/家长自己听"。把"对比"交还耳朵，App 只保证"录上了、能 A/B 对听"，不假装能判音准。**好处**：诚实，不踩 §7.6（不哄、也不假判）。**疑点**：这算不算退回"只放音"的边缘、§7.6 满不满意。
3. **二阶段接 ASR / 发音评测**（砍cinematic §2.2 本就写"数据驱动二阶段"）：长期靠真音准评测解决。**疑点**：成本/时机，本阶段（只 Unit-01）不启。

## 2026-06-03 技术现实校准（联网调研，详见 [[2026幼龄识字与跟读最佳实践调研]]）

「不接 ASR」的理由从「技术上必然做假」**诚实降级**为「**工程性价比 + 成熟度权衡，二阶段重估**」：

- 儿童 ASR **4–7 岁错误率全年龄段最高**、12–13 岁才与成人对齐（Learning Agency / JASA 2025）——**我们核心用户正好是最判不准的区间**。
- iOS 26 **SpeechAnalyzer 是「转写」框架、不是「发音评测」**，无中文发音打分（Apple Docs）。
- 2025 末前沿 **KidSpeak / K-Function** 证明趋势向好，但深读确认**全是英语 / 研究原型无开源 / 云端大模型跑不了 iPhone / 目标年龄 8–13 偏大**，本阶段都够不着。
- 能买的中文发音评分 = SpeechSuper / Speechace 云 API，**要钱要联网、主打成人**。

→ 所以方向 1（出声门）+ 方向 2（A/B 对听不判分）合并就是本阶段最诚实解；方向 3（ASR 评测）记为**二阶段技术储备**。

## 讨论时必须一起带上的硬约束

- 红线 §7.6 原文：跟读纠音必须做、**不能只放音，每字必须录音对比**。
- 零挫败：错不罚、永远给星、不羞辱。
- baked-only：只播预烘 mp3，**禁 OS TTS**。
- 不打视频军备竞赛、不接 ASR（本阶段）。
- 范围只 Unit-01；改动需用户许可才 commit。
