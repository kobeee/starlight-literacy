# Unit-01 产品级重构执行规划

## 定位

本文是 2026-05-05 之后 Mobile H5 / Unit-01 重构的权威执行规划。

本轮 review 的核心结论是：当前 H5 不能继续沿着“给单个字补一个漂亮小世界 / 补一个视频”的方向优化。`一 / 二 / 三` 的局部表达变好，但它没有形成可覆盖 20 个字和后续单元的识字系统；`一` 的 HyperFrames 视频也只是救援样片，未达到正式产品标准。

后续目标从“局部美化 demo”切换为：

```text
可扩展的识字内容模型
  -> 完整 20 字学习路径
  -> 全字可用的 H5 native micro-lesson
  -> 受控生图资产体系
  -> 少量高标准 HyperFrames 视频样片
  -> 批量生产和上线
```

## 权威性

如与此前日志冲突，以本文为准。

- 保留 [[03-开发日志/2026-05-04-Mobile-H5一二三小世界重构|一二三小世界重构]] 中“生活化承载物优先于裸横线”的判断。
- 降级“一二三小世界必须被特殊保护”的约束；它不能再压过完整 20 字路径。
- 保留 [[05-技术文档/Mobile-H5-HyperFrames教学动画优化方案|HyperFrames 教学动画优化方案]] 中“视频服务教学，不进入 App 壳”的原则。
- 新增约束：视频和生图都必须服从统一内容模型，不能反向决定课程结构。

## 产品原则

### 1. 每个字先是一节课，不是一张卡

每个汉字都必须有同一套课程字段：

| 字段 | 说明 |
|---|---|
| `glyphHook` | 孩子要记住的核心字形钩子 |
| `lifeMapping` | 从哪个生活物 / 场景过渡到字形 |
| `structureFocus` | 今天观察横、竖、点、框、上下、左右、内外中的哪一个 |
| `strokeGoal` | 书写页只练什么动作，不假装完整书法能力 |
| `soundCue` | 孩子听到的短句或带读词 |
| `contrastTargets` | 容易混淆的字，如 `日 / 目`、`人 / 大 / 天` |
| `nativeLesson` | 无视频时 H5 原生教学舞台如何呈现 |
| `practiceChecks` | 看形、听音、辨义、复认分别测什么 |
| `parentProof` | 家长中心可解释的学习证据 |
| `assetBrief` | 需要生图或插画时的资产 brief |
| `videoPlan` | 有视频时的分镜、voice cue、poster/final frame 要求 |

没有这些字段的字，不允许只靠临时图片、通用字卡或一个视频占位上线。

### 2. H5 native micro-lesson 是基本盘

视频是增强层，不是主链路。

所有 20 个字都必须先具备 H5 原生认字体验：

```text
生活承载物 / 场景提示
  -> 字形钩子
  -> 清晰大字
  -> 简短带读
  -> 书写动作目标
  -> 一道有效练习
```

只有当 native micro-lesson 已经成立，再为代表字做 HyperFrames 视频。

### 3. 生图工具用于体系化资产，不用于随机变漂亮

生图的目标不是“这个字更可爱一点”，而是建立稳定的视觉语法：

- 同一组字共享场景光线、构图尺度和材质。
- 汉字本身由代码 / SVG / 字体渲染，生成图不负责画汉字，避免文字错误。
- 生成图负责生活承载物、背景氛围、关键帧物件和视频素材。
- 不生成每个字完全不同的风格小剧场。

### 4. “学会了”必须有证据

进度状态从“点过”升级为“有学习证据”：

```text
seen：看过认字页
traced：完成书写动作
recognized：练习答对
mastered：间隔后复认答对
needsReview：答错或超时，需要复习
```

家长中心只展示可解释的证据，不再把“孩子点过下一步”包装成掌握。

## Unit-01 路径结构

当前 Unit-01 仍保持 20 字，但 UI 不再只突出前三个字。

### 课程分组

| 分组 | 字 | 学习重点 |
|---|---|---|
| 第 1 组 | 一 二 三 大 小 | 数量、线条、大小关系 |
| 第 2 组 | 上 下 人 口 手 | 位置、身体动作、基础象形 |
| 第 3 组 | 日 月 水 火 山 | 自然物象与字形轮廓 |
| 第 4 组 | 木 土 天 目 耳 | 自然结构、复合关系、器官辨认 |

### 字形范式

| 范式 | 字 | UI / 视频共用表达方向 |
|---|---|---|
| 线条数量 | 一 二 三 | 生活里的单条、两层、三层关系，不再裸画横线 |
| 大小位置 | 大 小 上 下 天 | 空间关系、身体伸展、上下参照 |
| 身体器官 | 人 口 手 目 耳 | 身体动作或器官轮廓，避免医学图解感 |
| 自然象形 | 日 月 水 火 山 木 土 | 温暖自然场景过渡到字形 |
| 易混辨认 | 日/目、人/大/天、一/二/三 | 练习和复习重点，不只做漂亮展示 |

## UI 重构策略

### P01 首页

保留长卷地图和当前真实进度状态，但首页 CTA 要指向“下一节课”，而不是只强化第一组三字。

### P02 单元页

从“阳光三小步”改为完整 20 字路径：

- 顶部展示当前组和下一字。
- 中部展示 4 个分组，每组可展开 5 个字。
- `一二三` 可以作为第 1 组中的样板，但不能占据整个单元页叙事。
- 未解锁组应展示轮廓和学习重点，不用空泛锁态。

### P03 认字页

统一为“认字小舞台”：

```text
顶部：返回 / 语音 / 认写练状态
主体：生活承载物 + 字形钩子 + 大字
信息：pinyin / phrase / 1-2 个词
底部：下一步
```

有视频时，视频替换主体舞台；无视频时，H5 用 `nativeLesson` 渲染同等级的原生微课。

### P04 写字页

短期不承诺“会写”，只承诺“跟着字形做动作”：

- 练习目标改为“画一横 / 两条线 / 站起来的一撇一捺”等动作语义。
- 判定从纯距离升级到方向、起止区域、笔顺进度。
- 家长中心文案避免“孩子已经会写”，改为“孩子完成了字形动作练习”。

### P05/P07 练习和测验

练习必须服务掌握证据：

- 答错进入 `needsReview`，不能点亮。
- 答对只进入 `recognized`，不直接等于掌握。
- 小测覆盖本组全部字，Unit Test 覆盖 20 字中的代表和易混组合。
- 练习题不再只取每组前三个目标。

### P11 家长中心

展示“证据链”：

```text
今天看过哪些字
哪些字完成动作练习
哪些字答对
哪些字需要复习
孩子用什么生活钩子记住了它
```

## HyperFrames 视频策略

### 先重做 `一`

`一` 不是正式 baseline，而是需要重做的标准样片。

标准样片要求：

- 4-6 秒，最多 8 秒。
- 0.8 秒内出现字形钩子。
- 字形是主角，角色和场景只做辅助。
- 语音使用可靠音轨，优先烘焙到视频或使用正式音频文件，不再依赖浏览器 Web Speech 定时拼接。
- 输出 `mp4 / webm / poster / finalFrame / metadata`。
- final frame 可独立作为弱网 poster。
- 通过 lint / inspect / render / 视频规格 / 截图 review。

### 再做 5 个代表字

只有 `一` 过标准后，才进入代表字样片：

| 优先级 | 字 | 覆盖范式 |
|---|---|---|
| P0 | 二 | 两条线、数量范式 |
| P0 | 三 | 三条线、节奏范式 |
| P0 | 人 | 撇捺支撑、身体动作范式 |
| P1 | 山 | 自然象形范式 |
| P1 | 火 | 动态自然物与结构高亮 |

这 5 个稳定后，再决定是否批量铺 20 字。禁止把模板换字后直接标为完成。

## 禁止事项

- 禁止继续只优化 `一 / 二 / 三`，却不补 20 字路径。
- 禁止把生成图片直接当汉字教学内容；汉字必须由可控字体 / SVG / canvas 渲染。
- 禁止让角色、动物、场景抢走字形主焦点。
- 禁止把未完成视频的字用临时图或旧素材冒充完成。
- 禁止在学习证据不成立时展示“已掌握 / 已完成”。
- 禁止不看截图只看 DOM 或语法通过就收口。
