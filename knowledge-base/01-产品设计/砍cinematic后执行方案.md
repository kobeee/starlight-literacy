## 1. 字库规模认知校准（最容易被忽略的根因）

### 1.1 实际规模 vs 之前的认知错配

| 范围 | 字数 | 单元数 | 之前我的错算 |
|---|---|---|---|
| **一期目标** | **1300 字** | **约 87 单元** | 误把 100 字（5 单元）当全貌 |
| 远期目标 | 1800 字 | 约 120 单元 | 同上 |
| 当前 MVP | 20 字 | Unit-01 已上 | — |

### 1.2 这个错配带来的关键校准

**所有"单字成本 / 单字生产周期 / 单字定价"全部需要乘以 13 倍重算。**

- 单字生产周期：HyperFrames 单字 1.5 天 → **1300 字 = 5.3 年生产周期**（数学上根本不可能）
- 单字付费定价：199 / 1300 字 = **¥0.15 / 字**（vs 洪恩宣传 ¥0.30 / 字 / 洪恩实际 ¥19.4 / 字）
- 单字反差化营销文案："**洪恩 388 给你 20 字，我们 199 给你 1300 字**"

### 1.3 字库规模直接决定生产形态

| 生产形态 | 单字工时 | 1300 字总工时 | 可行性 |
|---|---|---|---|
| HyperFrames cinematic | 1.5 天 | 5.3 年 | ❌ 数学上不可能 |
| 静态插画 + CSS 微动效 | 0.5 天 | 1.8 年 | ⚠️ 需进一步压缩 |
| 模板化插画（同字源族复用）| 0.1 天 | 130 天 | ✅ 可行 |
| **hanzi-writer 自动渲染（笔顺）** | **0 天**（库自带） | **0 天** | ✅✅ 最优 |
| baked TTS（edge-tts XiaoxiaoNeural）| 0.05 天 | 65 天 | ✅ 可行 |

**结论**：字库规模化是产品定位的硬约束 —— **不是"我们选择不做精美 cinematic"，是"1300 字的规模在数学上不允许精美 cinematic"**。这与红线 §7.8（视频精度不打军备竞赛）形成双重支撑。

## 2. 五大模块定稿

### 2.1 模块 1 · P04 写字描红（核心战场）

**地位**：反差化护城河 #1。洪恩 150 评论里被点名最痛的"乱画也判对" = 我们的市场空白机会（红线 §7.4）。

#### 技术方案

| 项 | 选型 | 依据 |
|---|---|---|
| 笔顺数据 | **hanzi-writer 开源库**（GitHub 3.5k★ · MIT） | 9000+ 汉字 SVG path 数据已训练好，覆盖一期 1300 全字 |
| 笔顺演示 | hanzi-writer `animateCharacter()` 自动渲染 | < 0.1s 实时生成，单字成本 0 |
| 实时判定 | hanzi-writer `quiz()` 模式 + 自定义 tolerance | 容差 ±15px（儿童手指 fat finger 适配） |
| 田字格 UI | 自绘 SVG（奶油米 + 蜂蜜金辅助线） | 田园暖彩规范 |

#### 双窗交互形态

```
┌─────────────────────────────────┐
│   ┌────────┐                    │
│   │  示范   │   ┌──────────────┐│
│   │  小窗   │   │              ││
│   │ (动画)  │   │   田字格      ││
│   │  ─→ 一  │   │   (孩子描红)  ││
│   └────────┘   │              ││
│                 │              ││
│   笔画 1 / 1   │              ││
│   ▸ 横         └──────────────┘│
└─────────────────────────────────┘
```

- 左：hanzi-writer 自动演示当前笔画（带运笔方向箭头）
- 右：孩子手指描红，hanzi-writer 实时判定
- 微循环：演示一笔 → 孩子描 → ✅ 给星 → 下一笔

#### 零挫败处理

判定不通过时（按 [[儿童零挫败设计原则]]）：
1. 第 1 次错：温和重播演示，不给红叉
2. 第 2 次错：放大判定容差到 ±25px
3. 第 3 次错：直接帮孩子高亮正确路径并放过，永远给星

**禁止**：扣分 / 红叉 / "再写一次"硬性要求 / 暂停学习流程

#### 工期估算

- 第 1 个字（"一"）：1.5 天（含双窗 UI 调试 + hanzi-writer 集成）
- 后续每字：5 分钟（仅配置选字 + 字源文案，库自动覆盖笔顺数据）
- **1300 字总工时：≈ 11 天**（仅含 P04 部分，含其他模块见 §5）

### 2.2 模块 2 · 跟读模块（反差化护城河 #2）

**地位**：洪恩明确短板（红线 §7.6 + 知乎家长共识），3-6 岁是语音意识关键期。

#### 技术方案（科学决策 · 非省钱）

| 项 | 选型 | 依据 |
|---|---|---|
| 标准音 | 复用 [[../05-技术文档/baked-audio-架构]] edge-tts XiaoxiaoNeural | 已 baked 全 Unit-01，量产链路通 |
| 孩子录音 | MediaRecorder API（wx.startRecord 小程序端） | 浏览器原生 + 微信原生，零依赖 |
| 反馈形态 | **WaveSurfer.js 双波形并排显示** | 自我回放镜像反馈 |
| ASR 评分 | **不接** | 见下 |

#### 为什么不接 ASR（这次定稿，不再钟摆）

**不是省钱原因（讯飞幼儿版 ~¥4 万/月@10 万 MAU，占收入 0.4%）**

**是科学原因**：
- Goswami 2002 + Anthony & Francis 2005 综述：3-6 岁语音学习关键不是"机器评分"，是"听自己 vs 听老师"的镜像对比
- 评分（即使软评分）激活焦虑系统；自我回放激活镜像神经元好奇系统
- 洪恩没做跟读不是做不起 ASR，是做 ASR 反而是错的方向

**第 2 期再观察**：上线 3 个月后看真实童声数据，**如果**有 30% 以上家长反馈"想知道孩子发音对不对"，**再**评估接讯飞幼儿版。**这是数据驱动的二阶段，不是"先合格线再优秀线"的拖延话术。**

#### 交互形态

1. 老师声「一」自动播放（baked audio）
2. 屏幕中央出现圆形「按住说话」按钮（随声音强度脉动）
3. 孩子按住读「一」→ 松开 → 自动回放 +
4. 双波形对比图（老师 vs 孩子），永远给一颗星
5. 「再听一次自己的」按钮，可无限次回放
6. 永远不给红叉，不显示百分比，不计入"准确率"

#### 工期估算

- 跟读模块 MVP：3-4 天（含录音 + 波形 + 零挫败 UI）
- baked audio 已覆盖全 Unit-01，新字仅需补 edge-tts 烘焙（5 分钟/字）

## 3. 付费 + 邀请模型定稿（2026-05-26 不再修改）

### 3.1 价格三层

| 层级 | 价格 | 范围 | 时效 |
|---|---|---|---|
| **免费** | ¥0 | Unit-01（20 字）完整体验 | 永久 |
| **单元单买** | ¥9.9 / 单元 | 任意 1 个付费单元（约 15 字） | 永久（一次性，无续费） |
| **一期买断** | ¥199 | Unit-02 ~ Unit-87（一期 1300 字全部）+ 远期 1800 字扩展免费升级 | 真永久 |

#### 9.9 单元单买的角色

- 服务 "还没决心买 199、想再试一个单元" 的家长
- 单买总成本（87 × 9.9 = ¥861）≫ 买断 199，**纯经济引导买断**
- **不阻止单买**：这才是"不付费解锁"的真正含义 —— 你可以慢慢来
- **不存在试用期**：花 9.9 买的就是该单元的永久权，不到期、不变灰、不弹付费墙

#### 199 一次性买断的角色

- 比洪恩 388 永久套餐便宜 48.7%（"半价"营销硬数据）
- 比洪恩实际交付（388 永久 = 20 字）单字成本便宜 99.2%
- **真永久承诺**：远期扩展到 1800 字时已购用户**自动免费升级**，无需再付费
- **写购买页第一屏正文加粗**：
  > ✅ 199 元一次性买断，含一期 1300 字全部内容
  > ✅ 未来字库扩展到 1800 字，**已购用户自动获得**，无需再付费
  > ✅ 7 天无理由退款（含已使用）
  > ✅ 不设自动续费

### 3.2 邀请奖励（双向 · 非现金）

| 角色 | 奖励 | 上限 |
|---|---|---|
| **被邀请人**（新用户激活） | Unit-02 + Unit-03 永久解锁（30 字内容，等值 ¥19.8） | 每个新用户 1 次 |
| **邀请人**（已付费 9.9 或 199） | 每邀请 1 人激活 → 获得 1 个"未购买单元的永久解锁权"（系统自动选下一个未解锁的单元） | 最多 10 次累计（≈ ¥99 等值内容） |
| **邀请人 · 已买断 199 的特殊情况** | 全单元已开放，无单元可解锁 → 改为"学伴礼物券"可转赠（送给另一位用户解锁单元） | 同上限 10 次 |

### 3.3 邀请奖励禁忌（红线扩展 · 不可越）

按本文档与 [[竞品洪恩用户反馈校准]] §7.9（待加章节）共同定立：

| 禁忌项 | 原因 |
|---|---|
| ❌ 现金红包 | 微信《小程序运营规范》4.16 禁止诱导分享换利益；个人所得税合规风险；客服 / 风控 / 提现复杂度 |
| ❌ 课程券（可流通） | 同上，触微信生态红线 |
| ❌ 积分（可兑换通用商品） | 同上，且会形成套利产业链 |
| ❌ 无上限激励 | 演变成"邀请副业"，违反红线 §7.5（游戏化克制） |
| ❌ 学习页弹邀请入口 | 违反红线 §7.5"不在学习页弹付费墙"延伸 |

**允许形态**：仅"产品内容权益"（单元解锁权 / 学伴券） + "情感符号"（徽章 / 推荐人记录），且**仅在家长中心入口可见**。

## 4. 字库规模化的生产可行性论证

### 4.1 1300 字单元拆分（建议）

按 15 字/单元 → 约 87 单元，分三阶段交付：

| 阶段 | 单元 | 字数 | 选字策略 |
|---|---|---|---|
| **MVP**（已上）| Unit-01 | 20 | 一二三四五六七八九十 / 大小多少 / 上下左右 / 人口手（独体象形为主）|
| **早期**（前 30 单元）| Unit-02 ~ 31 | 约 450 字 | 高频独体字 + 简单合体字 |
| **中期**（30~60 单元）| Unit-32 ~ 60 | 约 450 字 | 形声字 + 会意字 + 常用扩展 |
| **后期**（60~87 单元）| Unit-61 ~ 87 | 约 380 字 | 低频课标字 + 易混淆字辨析 |

选字优先级遵循 [[竞品洪恩用户反馈校准]] §7.7（教材衔接需教学法依据）—— 部编 + 字频 + 笔画难度，**禁止"HyperFrames 容易渲染的字优先"**。

### 4.2 生产线编排（单字成本核算）

每个字需产出：

| 资产 | 工时 | 成本累计 |
|---|---|---|
| 选字策划（教学法依据） | 5 分钟 | |
| P03 字源插画 + 微动效 | 0.5 天（模板化后 0.1 天） | |
| P03 字源旁白（edge-tts baked） | 5 分钟 | |
| P04 hanzi-writer 配置 | 5 分钟 | |
| 跟读 baked audio | 5 分钟 | |
| 单字测验题（A/B/C 三题） | 10 分钟 | |
| **总计** | **≈ 0.15 天/字（模板化后）** | |

1300 字 × 0.15 天 = **195 天 ≈ 6.5 个月**（1 人全职），团队 2 人可压缩到 3.5 个月。

### 4.3 与 yi-v5 cinematic 1.5 天/字 对比

- yi-v5 单字 1.5 天 × 1300 = **5.3 年**
- 砍 cinematic 后 0.15 天/字 × 1300 = **0.65 年**
- **效率提升 10 倍**

这不是审美降级，是**字库规模在数学上倒逼的工程化选择**。

## 8. 不再钟摆式修改的硬约束

**自审 meta 教训**（来自 2026-05-26 推演过程）：

| 失误类型 | 表现 | 纠偏 |
|---|---|---|
| 钟摆式修改 | 被指出 "¥20 现金红包不合规" → 把整个邀请人激励改成"纯荣誉零现金" | 应最小化替换零件（"现金"→"内容权益"），不应整块推翻 |
| 隐性删项 | 把"9.9 月体验"误改为"9.9 单元买" 后，下一轮整理表格时**完全丢掉** 9.9 这一层 | 任何决策定稿后必须列在"已决策清单"，任何后续修改必须显式说"删除 X" |
| "合格线/优秀线"双线话术 | 用"先做 A 再考虑 B" 变相回避具体决策 | 定稿就要给"做"或"不做"的硬选择，理由可以是科学/经济/合规但必须二选一 |

**铁律**：本文档定稿后，任何修改必须以 "diff 块" 形式显式呈现 —— **新增什么 / 删除什么 / 替换什么**，不接受"重新整理一遍"导致的静默删项。
