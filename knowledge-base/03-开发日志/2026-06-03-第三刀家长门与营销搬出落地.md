## 1. 两个设计决策（用户拍板）

1. **家长门形态 = 算术验证**（非长按）：Apple 家长门推荐做法，真验证成人、护付费红线 §1；亲子共用定位下家长层可文字（[[护城河落地度审计与亲子共用定位]] 一）。长按孩子会模仿、验证强度弱。
2. **P08 营销 = 搬进家长中心**（非删除）：营销不丢，只换到家长门后家长看得到的位置（P09 付费页本就含完整反差化）。

### 2.1 营销搬出 P08 学习终点 — `Screens/P08ResultView.swift`
- 删洪恩对比文案块（`CompetitorContrast.hongenPrice...` 那段）+ 删「解锁后续单元（¥199 一期买断）」CTA（原 → `.purchase`）。

### 2.2 家长门中心化逻辑 — `Core/AppModel.swift`
- **接上原本悬空未用的 `@Published var parentVerified`**（line 35，审计 grep「验证」零命中即指它没接线）。
- 新增 `@Published var pendingGate: LearningRoute?` + `requestGated(_:)`（已验证直接 `go`，否则挂起）/ `passGate()`（标记已验证 + 放行挂起页 + 清空）/ `cancelGate()`。
- **本会话验证一次即放行**（`parentVerified` 会话级，杀进程重置——防误扣够用、不反复弹烦家长）。

### 2.3 `ParentGate` 组件 — `DesignSystem/SharedComponents.swift`
- 纯逻辑 `ParentChallenge`（可单测）：`a×b`，`a/b ∈ 3...9`（不出 ×0/×1 送分题），`answer = a*b`。
- 视图：暗化遮罩 + 卡片「请家长完成验证」+ 算术题 + 数字键盘（1-9 / ⌫ / 0 / ✓ 金色）+ 返回。答对 `onPass`；答错 → 抖动提示 + 清空 + **换新题**（防瞎试）。

### 2.4 RootView overlay + 入口接线
- `RootView`：`model.pendingGate != nil` 时 overlay `ParentGate`（zIndex 10），`onPass=passGate` / `onCancel=cancelGate`。
- `P01MapView` 底栏：「付费方案」→`requestGated(.purchase)`、「家长中心」→`requestGated(.parentCenter)`；**「小星宝库」保持 `go(.treasury)` 开放**（孩子向成就展示，无商业）。
- `P10TreasuryView` 「去家长中心」CTA → `requestGated(.parentCenter)`。
- `P11ParentView` 「查看付费方案」→ `go(.purchase)` 不变（已在家长中心 = 已过门）。
- ⚠️ `-uiTest -route purchase/parentCenter` 直接赋 `route`，**不走 requestGated → 不弹门**（截图/录屏工具不受影响）。

### 2.5 测试 — `StarlightLiteracyTests/ParentGateTests.swift`（新文件，需 xcodegen）
- 5 例：①算术答案恒 a×b、操作数 3...9 ②未验证 requestGated 拦门（pendingGate 挂起、route 不变）③passGate 放行 + 解锁 + 清空 ④会话内已验证再请求直接放行不挂门 ⑤cancel 不跳页。
