## 4. 关键技术 / 经验沉淀

### 4.1 Overlay 模式：absolute 不 fixed
phone preview shell `.screen` 有 `overflow: hidden`，所有覆盖层必须 `position: absolute; inset: 0` 相对 `.screen`，**用 fixed 会被裁掉**。本轮 4 个全屏覆盖层（`.first-guide` / `.replay-card` / `.micro-review` + celebrate 弹层）都用同一套 z-index 分层（9300 / 9500 / 9400），互相可叠，不互踩。

### 4.2 强制不可跳过 = 无 data-action
`.replay-card` 强制 3s 不可跳过，靠的是**整个卡片没有任何 data-action**——孩子只能等定时器。这比 disable 按钮 / 拦截事件都更稳，且与 SPA 状态机契合。

### 4.3 状态 flip 检测 = 模块级 last* 变量
E-4 破雾、D-3 首次引导、首次播放欢迎语，都用同一种模式：**模块级 `lastX` 变量记录上一次渲染时的关键状态，下一次渲染对比 flip**。比把状态塞进 `state` 干净，因为这些是"渲染副作用"而不是"渲染输入"。`lastIsUnitComplete` 初始 `null` 确保 already-complete 的回访用户不会误触发动画。

### 4.4 SW 版本三件套必须同步
`scripts/bump-h5-version.mjs` 一次性更新 `index.html` / `app.js` / `sw.js` 三个文件的 `v=` 标记。本轮 v32 → v33 → v34 共两次升级，没出现一处忘改导致缓存错乱。`npm run check:h5` 最末 `bump-h5-version --check` 是兜底闸门。

### 4.5 CDP `evaluate()` 必须 IIFE 包裹 return
audit 脚本里 `evaluate(cdp, ...)` 把字符串作为 expression 求值，**裸 `return` 会 `Illegal return statement`**。所有有逻辑的求值都写 `(() => { ...; return x; })()`。

### 4.6 audit 步骤超时要留余量
E-2 链路 `practice-correct-into-review` 需要等 3.3s 回放 + 280ms + 320ms + 420ms ≈ 4.3s，原 `STEP_MAX_MS = 4000` 卡死。改 8000ms。**audit 步骤超时设置必须按"链路最长等待 × 1.5"留余量**，不能按"理论最短"。
