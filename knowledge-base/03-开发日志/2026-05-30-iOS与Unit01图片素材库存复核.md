## 生图路径记录

本轮没有使用 `codex exec` 假想的 image-generation tool。当前环境经 memory 修正后，可信路径是：

```text
aicodewith proxy + Responses API + image_generation tool
wrapper model: gpt-5.5
底层：gpt-image-2
```

复用脚本：

```text
tools/recognition-video/scripts/build-scene-assets.mjs
tools/recognition-video/scripts/gen-scene-image.mjs
tools/recognition-video/scripts/chroma-key-to-alpha.py
```

执行命令：

```bash
node tools/recognition-video/scripts/build-scene-assets.mjs \
  --only yi,er,san,xiao,shang,xia \
  --concurrency 2
```

随后因 `yi` 初版像裸横线、`shang` 初版有粉色动线，又重跑：

```bash
node tools/recognition-video/scripts/build-scene-assets.mjs \
  --only yi,shang \
  --force \
  --concurrency 2
```

实现方式：代理生成品红 `#ff00ff` chroma-key 原图，再用 PIL 抠成透明 RGBA。透明背景不能直接请求代理模型；当前可靠路径是 chroma-key 后处理。

## 下一步

新 session 继续补图时建议按优先级：

1. App 基础品牌素材：AppIcon、启动/品牌图、分享图、必要的首页壳图。
2. Unit-01 字源演化素材：先只做象形字，不给指事字硬做直映法。
3. 进入 iOS 接入前再考虑尺寸降采样：当前 `scene-assets` 是 1024 方图，iOS 卡片使用可另产 512 或 768 imageset，避免包体无谓膨胀。
