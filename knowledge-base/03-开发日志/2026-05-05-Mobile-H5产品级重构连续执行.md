# 2026-05-05 Mobile H5 产品级重构连续执行

## 本轮定位

本轮不再按“Phase 1 / Phase 2 / Phase 3”分开排队，而是把 [[01-产品设计/Unit-01产品级重构执行规划|Unit-01 产品级重构执行规划]] 中的关键链路连续打通：

```text
统一课程字段
  -> 学习证据 progress
  -> 20 字完整路线
  -> 数据驱动认写练
  -> 家长中心证据链
  -> 缓存 / 校验 / 浏览器验证
```

## 已完成

- 新增 `src/shared/unit-01-lessons.js`：Unit-01 20 字全部补齐 `glyphHook / lifeMapping / structureFocus / strokeGoal / soundCue / contrastTargets / nativeLesson / practiceChecks / parentProof / assetBrief / videoPlan`。
- 新增 `scripts/check-unit-01-course-model.mjs`，并接入 `npm run check:h5`，确保 20/20 字和 11 个课程字段可校验。
- 将 progress schema 升到 v3：
  - `characters[id].seenAt`
  - `characters[id].tracedAt`
  - `characters[id].recognizedAt`
  - `characters[id].needsReview`
  - `characters[id].masteredAt`
- 修复跨天清空风险：不再因 `dayKey` 不同重置进度，日期键改成本地日期。
- 保留旧 `learnedIds` 迁移能力：旧用户数据会迁移成 `recognizedAt`，但主逻辑改用 evidence map。
- P02 单元页改为 4 组 × 5 字完整路线，不再只展示“阳光三小步”。
- P03 认字页改为统一 native lesson 舞台，所有字都从课程字段渲染。
- P04 写字页使用 `strokeGoal / structureFocus` 表达动作目标。
- P05 / P07 练习和小测改用证据模型：
  - 答错写入 `needsReview`
  - 答对写入 `recognizedAt`
  - 单元复认通过后写入 `masteredAt`
- P11 家长中心改为“看过 / 画过 / 答对 / 会认”的证据链展示。
- `一` 旧视频改为 `legacyRecognitionVideo`，不再作为正式 `recognitionVideo` 接入主链路。
- 资源版本统一到 v18，并更新 SW cache。
