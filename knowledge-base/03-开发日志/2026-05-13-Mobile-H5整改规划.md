# Mobile H5 整改规划（v0.1 已拍板）

> 视频生产由 codex 那边在另一侧推进，本规划只覆盖 **视频以外的全部 H5 整改**：UI 界面、自适应、悬浮按钮、家长 / 孩子分层、产品设计与理念。

---

## 0. 决策点（2026-05-13 已拍板）

| ID | 题目 | 选项 | 拍板 |
|---|---|---|---|
| D1 | 家长 / 孩子视角分离形态 | (a) 家长独立 shell / (b) 仅 P11 强化 | **(a)** |
| D2 | 首次引导形态 | (a) 新画 P00 / (b) 上下文引导组件 | **(b)** |

---

## 1. 优化目标（10 个硬指标 · 全部需自动化可验）

**孩子端**
- O1：首次打开 0 提示，3 步内能走到 P03
- O2：每字内部完成「教→练→巩固」3 段，单字停留 ≥ 40s
- O3：错答有 3s 教学回放，不再"标记就过"
- O4：中断后回来 1 步内能恢复到上次学到的字

**家长端**
- O5：P11 给 actionable 建议（"今天重点复习 X 和 Y"），不只数字
- O6：家长视角独立 shell：字号 +2pt / 暖灰底 / 信息密度提升 / 有"建议"卡

**工程**
- O7：375 / 390 / 414 / 768 四种 viewport + landscape 横屏不破
- O8：iPhone 安全区 inset 不被压
- O9：SW 真实生效 + 离线 P01–P05 可用
- O10：全局错误捕获 + 用户可见 fallback toast

## 3. 执行阶段（6 阶段，独立可验收）

### Phase A · 围栏先行（半天）

**不动业务代码，先把"不破坏现有 H5"卡住。**

- A1: `scripts/check-mobile-h5-routing.mjs` — 路由白名单 + USER_FLOW 一致性
- A2: `scripts/audit-mobile-h5-viewport.mjs` — 4 viewport × 6 路由 = 24 截图巡检
- A3: `scripts/audit-mobile-h5-runtime.mjs` — headless 跑核心路径，断言 0 console error
- A4: `scripts/bump-h5-version.mjs` — 一处改、三处同步（index.html / sw.js CACHE_NAME / APP_SHELL）
- A5: 扩容 `npm run check:h5` 把 A1/A4 静态部分纳入；新增 `npm run audit:h5:flows` 跑 A2/A3
- A6: 先跑一遍当前基线，截图存档作为"整改前"对照

**验收**：6 张基线截图归档 + check:h5 仍通过 + 新脚本独立可跑

### Phase B · 工程底座（1 天）

- B1: 重写 `sw.js`：cache-first + 网络后备 + 不再死循环 + APP_SHELL 加 baked audio
- B2: SW 注册去掉本地 unregister 矛盾，允许本地测试
- B3: 生成 manifest icons 192 / 512（用 emoji ⭐ + 暖底 PNG 自画或脚本生成）
- B4: 全局 `window.onerror` + `unhandledrejection` → 用户可见 toast + console.error
- B5: index.html 加 og:title / og:image / og:description
- B6: 删 `images/` 内 29 张无引用废稿（先 grep 全部引用做白名单）
- B7: 压缩 SW APP_SHELL 内两张 2-3MB 大图（或干脆移出 APP_SHELL，懒加载）

**验收**：`audit:h5:sw` 离线模式 P01-P05 可达 + manifest 加桌面有图标 + 强制抛错触发可见 toast

### Phase C · 自适应 + 悬浮按钮系统（1 天）

- C1: 废弃 `bottom-action--scroll`，建立 `.docked-cta` 系统：`position:fixed; bottom:calc(env(safe-area-inset-bottom) + 18px)`，宽度 = `.phone` 宽，z-index 分层
- C2: P02 / P03 / P04 / P05 / P07 / P08 / P11 主 CTA 全部迁移到 `.docked-cta`
- C3: 内容区底部预留 `padding-bottom: calc(.docked-cta 高度 + 24px)` 防遮挡
- C4: 横屏 landscape：在 `.app-shell` 加 `@media (orientation: landscape) and (max-height: 480px)` 强制 portrait 警示（"请竖屏使用"卡）
- C5: 全局 FAB 系统：`.fab-parent`（左上）`.fab-treasure`（右上），P02–P10 常驻
- C6: safe-area-inset 全局审计：所有 `.phone` 子页面统一用 `env(safe-area-inset-*)`，不再硬写 px
- C7: 路由切换后焦点重置到 `topbar__title`

**验收**：`audit:h5:viewport` 4 尺寸截图按钮位置正确 + 横屏触发提示 + FAB 在所有非 P01 页面可见

### Phase D · 产品设计三大件（2 天）

- D-1: **首次引导**
  - localStorage 增加 `onboardingShown` 标记
  - 进入 P01 第一次：欢迎语 baked audio + 第一关圆点旁手指指引动画
  - 进入 P03 第一次：字源插画旁手指 + "点我听字音"
  - 进入 P04 第一次：田字格旁手指 + "跟我画"
  - 跳过 = 不再出现，可在 P11 设置里重置
- D-2: **"上次到哪"恢复**
  - P01 顶部 sticky banner（仅当 `state.progress.lastActiveCharId` 存在且非已 mastered）
  - 文案："上次学到「X」，继续？" + 主按钮 + 关闭
  - 关闭后 24h 不再出现
- D-3: **家长视角独立 shell（D1=a）**
  - 进入 P11 时切换 `<main class="app-shell app-shell--parent">`
  - 家长 shell 特征：字号基线 +2pt、暖灰 #F4F0E8 底、信息密度高（metric grid 3 列变 4 列）、语气改"您"
  - P11 新增"今日建议"卡：自动从 `needsReview` 列表生成"今天重点复习 X 和 Y"；从 `evidenceCounts` 生成"易混点"；从 `elapsedMinutes` 生成"建议下次 X 分钟"
  - P11 内"今日重点字 X"可点击 → 切回 child shell + 进 P03 该字

**验收**：`audit:h5:flows` 冷启动→第一关引导→P03→P04→P05→P06→P07→P08 端到端通；`audit:h5:parent` 家长 shell 元素全部出现

### Phase E · 闭环增强（2 天）

- E1: **错答价值（D3=a）**：P05/P06 答错后插入 3s 教学回放卡（字 + 字源插画 + 重播一次 baked audio），不可跳过；3s 后自动进下一字
- E2: **每字 3 段闭环**：P03 教 → P04 写 → P05 练之后新增一段 60s 微复习"再看一眼"（重播视频后 1s + 字 + 释义），可跳过
- E3: **收星动效升级**：粒子动画 + 收星音效（CC0）+ 数字跳动
- E4: **关卡解锁破雾动画**：完成一组时 P01 上对应组的雾带做一次 600ms 散开动画

**验收**：`audit:h5:learning-evidence` 错答后存在回放卡 DOM + 每字总停留时间统计 ≥ 40s

### Phase F · 不做项（明确剪掉，避免范围爆炸）

- 今日任务卡 / daily habit hook
- 激励多元化（贴纸 / 伙伴 / 城堡）
- 宝库玩法（喂养 / 装饰）
- 间隔重复算法
- AI 推荐 / 个性化推荐
- 微信支付真实链路
- 重画视觉稿（仅在田园暖彩内微调）
- 重组代码到多文件（demo 阶段不值）
- 不动 HyperFrames 视频生产
