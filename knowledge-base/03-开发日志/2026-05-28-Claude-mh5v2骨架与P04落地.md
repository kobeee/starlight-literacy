### 2. 数据 schema（Task 2 关键约束）

`data/schema.js` 显式约束（不是注释、是常量）：

- `SCHEMA_VERSION = "v2.0.0-2026-05-27"`
- SKU 仅三档：FREE / UNIT(¥9.9 永久) / BUYOUT(¥199 一期 + 远期 1800 字免费升级)
- `INVITE_REWARD_TYPES` 只允许 `unit-unlock` / `gift-voucher`（红线 §7.9 · 禁现金 / 课程券 / 积分）
- `INVITE_CAP = 10`（强约束封顶）
- `AUDIO_LAYERS_FORBIDDEN` 显式列出 6 类被禁 OS TTS 触发点
  （执行删 14 处 speechSynthesis 是 Task 10，目前 schema 端只是埋了约束，没真删 v34 代码 — v34 整个废了所以这步只是新代码自检用）

`data/units.js` 一期 unit-01 的 20 字字源：
- 每个字 `etymology.source` 明示 甲骨/金/篆，`type` 限 象形/指事/会意
- **没有 直映法**（红线 §7.3）—— 我自审了一遍，没有"二=蝴蝶""三=山丘""大=小人""小=种子"这类硬凑

### 3. 田园暖彩 CSS 基板（Task 3）

**反差化护城河 #1 落点**（红线 §7.4 真笔顺判定 + 儿童零挫败）：

| 机制 | 实现 |
|---|---|
| 真笔顺数据 | hanzi-writer-data v2.0.1 `medians[]`，本地 vendor，离线可用 |
| 容差 | `leniency: 1.5`（≈ ±15px） |
| 错 1/2/3 次 | 文案降级（"方向反啦"→"看老师"→"慢慢来"），第 3 次起 hanzi-writer 自动 ghost hint |

| 完成 | CTA 解锁 + `is-celebrate` 弹动 + L5 starPop（SFX.available=false 时静默） |

**田字格**：用 CSS `::before`（横虚线）+ `::after`（竖虚线）+ `linear-gradient + background-size: 7px 1px` 做 dashed。无外部 SVG 资产，无 hanzi-writer 配置侵入。

### 风险 1（最关键）· P04 hanzi-writer 真实交互未人眼审

教训来自 [feedback_validator_pass_not_product_pass](../../../../.claude/projects/-Users-elvis-Documents-codes-challenges-2026-Apr-starlight-literacy/memory/feedback_validator_pass_not_product_pass.md) 和 [feedback_honest_delivery](../../../../.claude/projects/-Users-elvis-Documents-codes-challenges-2026-Apr-starlight-literacy/memory/feedback_honest_delivery.md)。

本轮做了：
- ✅ 静态资源 200 (hanzi-writer.min.js 37 KB / 一.json 373 B)
- ✅ 初次 headless 截图 80785 B（壳出来了，标题/卡片/田字格背景出来了）
- ❌ **第二次延长 virtual-time=10s 截图大小一字未动（80785 B）** → hanzi-writer 的 SVG 没在 virtual-time 时钟下挂上
- ❌ **没有任何真浏览器（含 iOS Safari / Chrome devtools mobile）的实际描红交互通过**

**可能根因**（按可能性排序，未验证）：
1. UMD `<script>` 异步注入 + `queueMicrotask` 的执行序在 headless virtual-time 里被冻住
2. hanzi-writer `charDataLoader` 回调是同步 `onComplete(data)` 但 fetch 是异步 → 我现在已经预先 `await loadCharData` 再 create，理论上应该没问题，但没真跑过
3. `aspect-ratio: 1` 在 SVG 嵌套时塌成 0 高度（CSS 2024 这个坑还在）

**所以 Task 4 不能勾"完成"**。它是 "代码层完工 / 真机不验证不算数"。

### 风险 2 · 视觉资产基本是空的

所有图卡（P05）、字源插图（P03）、宝库勋章（P10）都还没产。Task 12 列在最后，但 P03/P05 不出图就只能挂占位，得在 Task 6/7 之前先动 12 的一部分。

### 风险 3 · M3 跟读没动手就已经有疑问

WaveSurfer 双波形对比"两条波看起来像就算过"这件事，能不能让 3-6 岁孩子感知到差异，**没有产品验证**。如果只是视觉对照而无任何感官闭环（不是 ASR、不是发音评分），可能就是个心理安慰摆设。下一轮开 Task 5 前要先停下来跟用户对一次"无 ASR 的跟读到底能给什么真反馈"。
