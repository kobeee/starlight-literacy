## 1. 关键反馈与误判修正

### 1.1 错误 1 · 工程验收 ≠ 产品验收

我读 memory `project_h5_demo_closed.md` 看到 "Phase A→E + D 二轮全 ✅ / v34 / 不再追加新 phase"，**误判 v34 已经能见人**。

用户原话："哥，现有的H5也是个半成品都不是啊。。。拉垮得一批，你是想砸饭碗还是咋地"

**根因**：当时 v34 整改只验工程围栏（路由/viewport/版本/sw/敲门审计），没验**产品视角**（孩子家长真打开看见什么）。memory 标的 "✅" 是工程闭环不是产品验收。

**沉淀**：[[../../memory/feedback_h5_engineering_vs_product_acceptance|工程验收 ≠ 产品验收]]（待补 memory，本日志先标记）。

### 1.2 错误 2 · 脑补诊断，不去真启动

我列了 6 个"可能拉垮点"请用户打勾。用户："整个H5啊大哥，你可以自己启动然后用浏览器打开看看的啊"

**修正**：实启 `npm run dev:h5`（顺手加了 `.claude/launch.json` 的 mobile-h5 配置 4173 端口），用 preview MCP 完整走 P01→P09，列出 7 项工艺崩坏 + 红线触雷：
- 深咖啡色"一"icon、CTA 文字截断、黑色"开始"按钮、顶部按钮无标签
- P03 一/二字内部矛盾、宝库无含义小圆点
- **直映法**在 P05/P06/P09/单元详情全线触雷 → 触红线 §7.3
- **P04 写字判定是假的**（没接 hanzi-writer）→ 触红线 §7.4
- **跟读模块完全不存在** → 触红线 §7.6
- 付费/退款/邀请 0 接入

### 1.3 错误 3 · 诊断只走视觉，漏听觉

preview MCP 无声，我没主动 grep 声音入口。用户："那段语音播报，'欢迎来到星光识字xxx'，听到没，简直灾难啊。。。。。。。就这种问题都没发现吗"

**修正**：
1. 真诚承认盲区
2. `grep -rn "speakText\|speechSynthesis"` 出 **14 处**调用 + `speakText` 最终走 `window.speechSynthesis.speak()` OS 系统 TTS
3. 对照 `assets/audio/unit-01/` 60 个 baked mp3（20 字 × 3 文件），**整个应用层语音零 baked 覆盖**，只覆盖 P03 字级播放
4. 诊断 SOP 修订：以后审儿童产品，**必须主动 grep 所有声音触发点**，不能只看不听

### 1.4 错误 4 · 单点工艺化一个本来该删除的功能

我提议"把欢迎语 baked 化"。用户："不要搞什么欢迎语，后面换背景音乐了，欢迎语给谁听？？？简直昏招百出啊你。。。"

**根因**：工艺化一个本来该删除的功能是负收益。儿童产品声学层级要从"BGM + 必要语音"整体设计，**不是抓已有语音点逐个工艺化**。

**重新画的声学 6 层**：
| 层 | 来源 | 状态 |
|---|---|---|
| L1 BGM | 田园暖彩调性 loop | 待加 |
| L2 字带读 | edge-tts XiaoxiaoNeural baked | 已有 60 mp3，需扩到 1300 字 |
| L3 字源旁白 | edge-tts baked，与 P03 SVG 同步 | 待加 |
| L4 跟读老师标准音 | edge-tts baked，单字 + 短语 | 已有 phrase mp3，需对接 WaveSurfer |
| L5 拟声微反馈 | 短 sfx | 待加 |
| L6 错答 3s 教学回放 | 字带读 + 字源旁白拼装 | 框架已有，需对接 baked |

**应删除层**：欢迎语 / 按钮反馈语 / first-guide 引导语 / 家长中心朗读 / 操作播报 / **所有 OS TTS fallback**

### 1.5 错误 5 · 分阶段思维

我多次列"第一刀/第二刀/Week 1/优先级 P0"。用户："不要单点去解决问题... 不分什么阶段和优先级，只有一个唯一的目标... 不要用常规的研发思路... 老算什么开发时间"

**修正**：给出一份**不可分割**的全新 H5 目标定义书，所有事情都得发生，没有先后。AI 视角下"开发时间"是伪命题，聚焦事情本身。

## 2. 最终决策（2026-05-27）

### D1 · 砍 v34，另起 `src/clients/mobile-h5-v2/`

- 不动 `src/clients/mobile-h5/` v34，保留作回滚兜底
- mobile-h5-v2 从零，不继承旧目录结构 / 不继承旧 sw.js / 不继承旧 build pipeline / 不继承旧数据形态
- 旧版唯一可复用：`src/clients/mobile-h5/assets/audio/unit-01/` 60 个 baked mp3
- 其他全部重产（特别是视觉资产，用 gpt-image-2）

### D2 · gpt-image-2 调用方式记忆化

- **主路径**：本地 codex `codex exec` 进 `tools/recognition-video/codex-skill/starlight-video-agent/SKILL.md`，agent 内调用 codex 内置 `image-generation` 工具
- **Fallback**：Responses API 代理 `https://api.aicodewith.com/chatgpt/v1`，wrapper model `gpt-5.5`，见 [generate-via-responses.mjs](../../tools/recognition-video/scripts/generate-via-responses.mjs)
- **prompt 硬规则**：显式 `transparent PNG with alpha channel (RGBA)` + 禁 `backdrop/floor/shadow/halo`，附 style reference image
- **反作弊**：一次 call 一组合 / 禁脚本拼 spritesheet / 失败只切一次 chroma-key fallback 不重试
- 沉淀到 [[../../memory/reference_gpt_image_2_calling|memory: gpt-image-2 调用方式]]

### D3 · 全新 H5 目标定义书（不可分割）

mobile-h5-v2 一次交付，覆盖以下全部内容（无优先级、无阶段、无开发时间估算）：

#### 3.1 视觉资产（gpt-image-2 全部重产）
- 田园暖彩 8-12 风格基板（晨光草地 / 黄昏麦田 / 蜂巢花田 / 溪边石板 / 茅屋村落 / 木桥竹林）
- 1300 字单字主插画（按字源分类批量生图，遵循 1 call 1 组合硬约束）
- P01 学习地图长卷（替换现有平面 SVG）
- P03 字源讲解 SVG 资产（每字配真象形 / 真会意，禁直映）
- P05 看图认字图卡（每字 3-5 张同主题不同形态）
- 庆祝 / 解锁 / 宝库等动画基底
- 全部 RGBA 透明，命名禁 `vN`

#### 3.2 五大学习模块（产品红线对齐）
- **M1 P03 字源讲解**：静态 SVG + CSS 微动效，禁 cinematic，禁直映法（红线 §7.3）
- **M2 P04 写字描红**：hanzi-writer 双窗（演示 + 描红）+ ±15px 容差 + 错 3 次自动放过（红线 §7.4 + 零挫败）
- **M3 跟读对照**：WaveSurfer 双波形对比，不接 ASR（红线 §7.6 + 科学决策）
- **M4 P05 看图认字**：每字配 3-5 张真实场景图（gpt-image-2）
- **M5 P07 庆祝 + 复习 + 宝库 + 家长中心**：延用 v34 E-3 动效逻辑，UI 重做

#### 3.3 商业链路 demo
- 付费三层（免费 Unit-01 / ¥9.9 单元 / ¥199 一期买断 + 远期免费升级）
- 退款入口（家长中心 ≤2 步可达，红线 §7.1 §7.2）
- 邀请双向激励（被邀请人 Unit-02+03 / 邀请人未购买单元解锁权 ≤10 次，红线 §7.5 §7.9）
- 全部 mock，不接真实微信支付

#### 3.4 声学系统（6 层 + 删除层 见 1.4）

- L2-L4 全 edge-tts baked，manifest 驱动
- L5 sfx 资源库

- **彻底删 14 处 speechSynthesis 调用 + speakText 函数**

#### 3.5 文案重写
