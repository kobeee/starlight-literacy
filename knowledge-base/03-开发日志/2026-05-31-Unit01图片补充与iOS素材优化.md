# 2026-05-31 · Unit-01 图片补充与 iOS 素材优化

## 背景

用户要求：**不要动代码相关的，只考虑 Unit-01，把接下来缺的图片或者要优化的图片完成**。

本轮严格只处理图片 / 素材文件，不改 Swift、不改 project、不改业务逻辑。

## 完成项

### 1. 优化 `一` 的 scene 图

旧问题：`scene_yi` 容易看成厚木盘 / 托盘，对「一」的生活承载偏弱。

本轮换成更明确的**一根横放木质计数棒**：

```text
tools/recognition-video/assets/unit-01/scene-assets/yi.png
tools/recognition-video/assets/unit-01/scene-assets/raw/yi.png
src/clients/iOS/StarlightLiteracy/Assets.xcassets/scene_yi.imageset/
```

生成路径：

- 先尝试复用 `build-scene-assets.mjs --only yi --force`，生图成功但系统 `python3` 缺 `numpy`，后处理失败。
- 改用内置 `imagegen` 生成绿色 chroma-key 版：`one single horizontal wooden counting stick`。
- 用 `remove_chroma_key.py` 抠透明，白底检查边缘干净。
- 生成并同步 iOS `scene_yi@1x/@2x/@3x`。

验收：

- `scene_yi@1x/@2x/@3x` 均为透明 PNG。
- `yi.png` 为 `1024x1024 srgba`，alpha 范围 `0..1`。
- `_overview.png` 已更新，第一格现在是细长木质计数棒，不再像木盘。

### 2. 修复 `手` 的 oracle 空图

旧问题：`oracle_shou@3x.png` 实测 `maxAlpha=0 / meanAlpha=0`，整张全透明。根因不是 iOS 代码，而是本地 `shou-oracle.svg` 用 `stroke` 线条，当前 ImageMagick SVG 栅格化路径不吃 stroke，导致输出空图。

本轮处理：

```text
tools/ios-assets/oracle-svg/shou-oracle.svg
src/clients/iOS/StarlightLiteracy/Assets.xcassets/oracle_shou.imageset/
```

- 将 `shou-oracle.svg` 转成当前管线可栅格化的填充型 SVG。
- 重生成 `oracle_shou@1x/@2x/@3x`。
- 白底检查确认可见；`oracle_shou@3x` 现在 `alphaMax=1`，不再是空图。

注意：这仍是**本地手形兜底线稿**，不是已验证的权威甲骨来源。后续若找到可验证 CC0 / Commons `手` 甲骨 SVG，仍应替换源 SVG 后重跑生成。
