## 落地内容

### 1. 数据底座（纯函数 `Core/ReviewSchedule.swift` 新增）
- 艾宾浩斯遗忘曲线档位 `intervalsDays = [1,2,4,7,15]` 天，5 轮后「巩固毕业」不再排。
- `dueDate(stage:since:)`（毕业返回 nil）/ `isDue(stage:since:now:)` / `advance(stage:)`（封顶毕业档）。
- 无副作用、时间由调用方传入 → 好测。

### 2. `Core/AppModel.swift`（接入）
- 新增 `passedAt`/`reviewStage`/`lastReviewAt`（每字时间戳）+ `clockOffset`（仅 -uiTest 快进）。
- `markWritten` 首次通过登记复习曲线起点（重学不重置）。
- `dueReviewIDs(now:)` 算今天到期字（按 order 排，毕业不排）；`recordReview(id)` 复习成功推进档位 + 刷新 `lastReviewAt`（零挫败：只在答对/放过时调）。
- 留存证据 `reviewedCharCount`（≥1 轮）/ `masteredCharCount`（毕业）→ 亮给家长。
- `ProgressDTO` 扩展（Date 存 timeIntervalSince1970，**旧字段可选解码向后兼容**；旧存档已通过的字加载时补登记起点，不丢老用户）。
- launch arg `-fastForwardDays N` 把 `now()` 快进 N 天（单 Unit 演示到期）；`-route review`。

### 3. `Screens/P12ReviewView.swift`（新增 · 复习关）
- 进页快照 `dueReviewIDs()` 成队列，逐字再认（复用看图认字 pattern：图(义)+念音 → 纯汉字候选认形，`buildOptions` 复用混搭干扰 + relax 降级）。
- 认对 `recordReview` 推进档位 → 下一字；零挫败（错答 3s 回放、错 4 次放过仍推进、永远给星）。
- 全认完 → 留存庆祝态「还记得！隔了几天你认出了 X / N 个字」→ 回地图。

### 4. `Screens/P01MapView.swift`（入口）
- `dueReviewIDs` 非空时 hero 下出现「今日复习 N 字」卡（孩子向：大数字 + 字预览 + 跳动手指）→ `model.go(.review)`，**不过家长门**。

### 5. `Screens/P11ParentView.swift`（感知层）
- 新增「学习留存（孩子真的记住了吗）」卡：已学完 / 隔天还认得 / 已巩固 / 今日待复习，+ 一句「艾宾浩斯曲线安排、靠孩子自己再认出字形判定、不是放段音糊弄」。这是护城河「真学会」亮给家长的证据（[[feedback_moat_capability_vs_perception]]）。

### 6. `Screens/RootView.swift`：`.review` → `P12ReviewView()`。
