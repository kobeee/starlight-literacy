# 2026-05-30 · iOS 图片素材接入与基础品牌图补齐

### 2. 可复跑 iOS 图片生成脚本

新增：

```text
tools/ios-assets/generate-ios-image-assets.mjs
tools/ios-assets/oracle-svg/
```

脚本能力：

- 从 `tools/recognition-video/assets/unit-01/scene-assets/` 读取 20 张 1024 RGBA 正图，生成 iOS `scene_*.imageset`。
- 从 `tools/ios-assets/oracle-svg/` 读取 14 个字源 SVG，生成 iOS `oracle_*.imageset` 模板图。
- 生成基础品牌图：
  - `AppIcon.appiconset/AppIcon-1024.png`
  - `LaunchBrand.imageset`
  - `ShareCard.imageset`
- 输出均落在：

```text
src/clients/iOS/StarlightLiteracy/Assets.xcassets/
```

### 3. iOS Asset Catalog 已补齐

新增 / 更新资产：

- `scene_*`：20 组，覆盖 Unit-01 全 20 字，用于 P03 认读绑定 / P05 看图认字 / 首页旅程卡。
- `oracle_*`：14 组，覆盖 `ren kou shou ri yue shan shui huo mu mu-eye er-ear tian da tu`，用于字源彩蛋。
- `AppIcon`：补 1024 PNG，不再是空壳。
- `LaunchBrand`：启动品牌图。
- `ShareCard`：家长中心后续分享卡图。

尺寸策略：

- `scene_*`：`256 / 512 / 768` 三档。
- `oracle_*`：`256 / 512 / 768` 三档，模板渲染。
- `LaunchBrand`：`320 / 640 / 960`。
- `ShareCard`：`400x210 / 800x420 / 1200x630`。
