## 1. 主路径五步重排（方案 §3）

旧（首版）：字源讲解 → 写 → 练。
新：**认读绑定 → [象形字源彩蛋] → 看图认字 → 跟读 → 写（=完成）→ 复现**。

- `LearningRoute` 新增 `case recognize(String)`；`AppModel` 路由链：`startUnit→.recognize`，`routeAfterRecognize`（象形→`.etymology`，否则→`.imageCard`）→`routeAfterImageCard`→`.followRead`→`routeAfterFollow`→`.writing`→`routeAfterWriting`（有下一字→`.recognize`，否则→`.group`）。
- **写字语义变化**：原来写是中间步，现在是**完成步**——`markWritten` 才写 `passedIDs` 并结算 `starsByChar`（取自看图认字表现 `identifyStars`，max 不降星）。

## 2. 顺序门重定义（护城河本意没动，只换了门的顺序）

`AppModel` 模型层四道门，每道守上一步，绕过 UI 直调模型也跳不过：

```
markRecognized(id)              // 认读，无前置
markIdentified(id, stars)       // guard recognizedIDs.contains(id)
markFollowed(id)                // guard identifiedIDs.contains(id)
markWritten(id)                 // guard followedIDs.contains(id) → passedIDs + 结算星级
```

`MoatGateTests` 重写 7 条：三道"跳步被拦"+ 合法顺序逐门解锁 + 星级取 max 不降 + 每字独立门 + seedDebug 置满。配合 `StrokeJudgeTests` 6 条 = **14 单测全 SUCCEEDED**。

## 6. 两个工程坑（记忆已沉淀）

1. **新增 `.swift` 文件后必须 `xcodegen generate` 重生 `.xcodeproj`**——项目用 XcodeGen glob，新文件不在 `.pbxproj` 里会报 `cannot find P03RecognizeView in scope`。普通 build 一开始"过"是假象。
2. **`xcodebuild ... | tail` 的退出码是 tail 的，不是 xcodebuild 的**——被骗以为 build 成功。改 `xcodebuild ... > log 2>&1; echo $?` 才看到真实失败。
