# 2026-05-10 Mobile H5 一字视频小动物与 P03 播放页修复

## 背景

用户指出产品级重构中的两个严重问题：

- `一` official 认字视频“拉垮”，没有之前反复强调的小动物动画。
- in-app 浏览器里的 P03 认字视频播放页视觉层级混乱，“一言难尽”。

本轮先用 in-app 浏览器复核真实页面，再修视频产物和 H5 承载页。

## 诊断

### 1. 视频产物缺陪伴角色

`tools/hyperframes-one/index.html` 的 official v1 composition 已经有小路、苹果、木棒、横线、pinyin 和 final frame，但没有小动物层。

这和 [[05-技术文档/Mobile-H5-HyperFrames教学动画优化方案|HyperFrames 教学动画优化方案]] 中“可保留少量动物/云朵做陪伴，但角色始终服务于字形记忆”的方向不一致，也不符合用户之前对“小动物动画”的明确要求。

### 2. H5 播放区把视频当背景压住

P03 认字页在有 official 视频时仍渲染了原生教学层：

- `lesson-stage__sky / sun / ground`
- `lesson-stage__strokes`
- `lesson-stage__glyph`
- `lesson-stage__cue`
- 默认 `lesson-proof-card`

结果是视频、字卡、提示卡、下方讲解同时出现，视觉上像“视频播放器被原生 UI 盖住”，孩子看到的不是一个清楚的认字舞台。

## 修复

### 1. HyperFrames 加小动物陪伴层

在 `tools/hyperframes-one/index.html` 引入已有动物素材：

- `assets/animals/rabbit.png`
- `assets/animals/bluebird.png`
- `assets/animals/squirrel.png`
- `assets/animals/ducklings.png`

规则：

- 小动物只放在画面边缘和草地，避免进入中心字形区。
- 动作只用 `opacity / x / y / scale / rotation`，保持 deterministic GSAP 时间轴。
- 兔子配合小路入场，蓝鸟轻飞，松鼠在苹果段出现，小鸭在木棒段慢慢走动。
- final frame 保持安静可读，动物不抢 `一` 的横线和 `yī`。

更新：

- `tools/hyperframes-one/index.html`
- `tools/hyperframes-one/meta.json`
- `src/clients/mobile-h5/assets/recognition/yi/yi-stage-official-v1.metadata.json`
- `src/shared/unit-01.js`

版本标记：

```text
2026-05-10-official-v1b-animal-companions-h5-stage-fix
```

### 2. 重渲染 official 资源

重新渲染 silent MP4，再合入 baked audio：

- `tools/hyperframes-one/renders/yi-stage-official-v1-silent.mp4`
- `tools/hyperframes-one/renders/yi-stage-official-v1.mp4`

- `tools/hyperframes-one/renders/final-frames/yi-stage-official-v1-poster.png`
- `tools/hyperframes-one/renders/final-frames/yi-stage-official-v1-final.png`

同步到 H5：

- `src/clients/mobile-h5/assets/recognition/yi/yi-stage-official-v1.mp4`

- `src/clients/mobile-h5/assets/recognition/yi/yi-stage-official-v1-poster.png`
- `src/clients/mobile-h5/assets/recognition/yi/yi-stage-official-v1-final.png`

注意：第一次合音使用 `-shortest` 会把视频截到 `5.54s / 133 frames`，已纠正为不加 `-shortest`，保留完整 `5.833333s / 140 frames`，音频自然结束后画面继续稳定停留。

### 3. H5 正式视频模式降噪

`src/clients/mobile-h5/app.js` 中 `renderRecognitionMedia()` 改为：

- 有 official video 时只渲染 `poster + video + 轻量 replay`。
- 不再叠加原生 `glyph / strokes / cue / sky / ground`。
- baked audio 视频仍不强制 `muted`，点击舞台可播放视频自带音轨。

`renderRecognize()` 改为：

- official video 默认不显示 `lesson-proof-card`，避免和视频字幕/旁白重复。
- 只有孩子点击 `小路 / 苹果 / 木棒` discovery chip 后，才显示反馈卡。

样式更新：

- `lesson-stage--video` 固定 `16 / 10` 横向教学舞台比例。
- poster 作为弱网/自动播放失败 fallback。
- replay 是右下角轻量圆形按钮，不再把视频包装成厚重字卡。

资源版本：

```text
v23 -> v24
```

## 验收

通过：

```bash
npx hyperframes lint
npx hyperframes inspect --at 0.3,0.8,1.6,3.2,4.8,5.7 --json
npx hyperframes render -o renders/yi-stage-official-v1-silent.mp4 --fps 24 --quality draft --workers 1
```

关键结果：

- HyperFrames lint：0 errors / 0 warnings。
- HyperFrames inspect：0 issues。
- MP4：`1280x800 / 24fps / 5.833333s / 140 frames`，含 AAC audio。
- WebM：`1280x800 / 24fps / 5.834s`，含 Opus audio。
- `Mobile H5 guardrails ok: v24 resources, legacy gate, visual audit hook, official video policy.`
- in-app 浏览器进入 P03 `一` 页面后，视频不再被原生字卡遮挡；点击视频舞台后进入播放状态，画面中可见小动物陪伴层。

## 后续约束

- `一` 当前 official baseline 已升级为 v1b；后续不要回退到没有小动物陪伴的 v1 观感。
- official 视频进入 H5 时，H5 只负责承载视频、poster fallback、轻量 replay；不要再叠原生 `glyph / cue / strokes`。
- 小动物可以出现，但必须在边缘、慢动作、低刺激，不能比字形更抢眼。
- 后续代表字 `二 / 三 / 人 / 山 / 火` 的样片也必须先过“视频产物质量 + H5 承载页截图”双验收，再接入主流程。
