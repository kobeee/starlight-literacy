# 2026-05-08 Mobile H5 全链路 UI 验证

## 本轮目标

按用户要求“先不管声音，实际看看 UI”，使用 in-app browser 把当前 Mobile H5 走一遍完整链路，对照 [[01-产品设计/Unit-01产品级重构执行规划|Unit-01 产品级重构执行规划]] 和近几日开发日志，确认 Phase 0 / Phase 1 / Phase 2 是否真的在运行时成立，而不是只在文档和 lint 里成立。

## 通过项

### 课程模型与证据模型

- `localStorage.starlight-literacy-mobile-h5-v1` 存的 `characters` 字段对每个字记录 `seenAt / tracedAt / recognizedAt / masteredAt / needsReview / lastMissAt`，状态码缩写为 `STRM`。
- 跑完一组后，5 个字真实进入 `STRM`；第 2 组首字 `上` 仅 `S`。
- 错答会真实降级：第一次走 P07 时我误点了 `二`，于是 `三` 退化为 `STR + N!`，应用结束 quiz 后**自动跳到 `三` 的认字页要求复习**，而不是粉饰为已通关。
- 重新走 认 → 写 → 练 → P07 五题全对后，`三` 才升级为 `STRM`，`needsReview` 清空。
- 这条链路完全符合 Phase 1 的“学习证据，不是点过”的设计。

### P01 学习地图

- 田园暖彩长卷正常加载（`p01-bg-redraw-road-centered-20260426.png` + 田园叠层 + 动物边缘叠层）。
- 三态视觉到位：第 1 组金色 ✓ 已点亮、第 2 组金色播放按钮 + “从这里开始”、第 3 组灰球 + 闪电锁态。

### P02 单元页

- 顶部 hero card：`第 2 组 · 位置、身体、动作 / 今天从「上」开始 / 一竖站着，短横在上面 / shang`，并显示当前字大字预览。
- 4 组都展示，每组 5 字带 `lifeMapping` carrier 文案与 `会认 / 看过 / 待学` 状态：
  - 第 1 组 5/5 — 一/找小路、二/数木板、三/摆小山、大/张开手、小/点小芽
  - 第 2 组 0/5 — 上/找上面、下/接雨滴、人/站稳、口/围一圈、手/挥小手
  - 第 3 组 0/5 — 日/点太阳、月/找月光、水/分水流、火/点火苗、山/立山峰
  - 第 4 组 0/5 — 木/伸树枝、土/种小芽、天/找天空、目/眨眼睛、耳/听风铃
- 顶部统计 `6 看过 / 5 画过 / 5 答对 / 0 复习`、证据进度条 25%（5/20）。
- 不再是“前三字精制、后十七字掉档”的状态。

### P03 认字 native micro-lesson

- 同一套舞台对所有字成立：返回 / 语音 / 认写练 tab → 大字 + 字形钩子 + 生活承载物 → 字形钩子 / 生活里找 / 词 chips → “画一画” CTA。
- `小` 用真实字形 SVG 渲染（不是抽象几条线）；`上` 用真实字形 + 云朵梯子场景；`一/二/三` 用承载物 + 字形钩子语义化的横线，不是裸笔画。
- 这一层把 [[2026-05-04-Mobile-H5一二三小世界重构]] 里“生活化承载物优先于裸横线”的洞察推广到全字。

### P04 写字

- strokeGoal 驱动：`三` 显示“横线数量：三条，间距均匀 / 从上到下画三条横线”。
- 提供 `再试一次 / 我画好了` 两条路径。零挫败设计成立。

### P05 单字证据练习

- 两种题型：看图（stage 显示字形，cue 是“X 座小山排好队，帮我们记住「X」”）和听一听（stage 是 ♪ 按钮 + 长 cue，无字形预览）。
- 答对后绿色描边卡 + “找到了，「X」亮起来了。” + “收进宝库” CTA。
- 答错走 P05 “再看一眼”路径（之前会话已验证，本轮未再触发）。
- 看图题的 `quiz-art` 通过 `--char-color` CSS 变量与正确答案卡对齐，可作为运行时识别答案的稳健信号。

### P07 第 1 组复认

- 共 5 题，混合 `看图，选出正确的字` 与 `听一听，选出正确的字`。
- 听一听题的 cue 句式以目标字结尾（如“两条就是二。”、“中间一竖，两边小点，是小。”），可被解析。
- 全部答对后**直接路由到下一组首字 P03（上）**，没有独立庆祝过场。
- 答错的字进 `needsReview` 而不是直接通过，验证后会拒绝离开第 1 组。

### P10 小星宝库

- 头部 `小星宝库 / 5 个字已答对`，主区为 4×5 的 20 宫格，每格按字本身的 `--char-color` 着色：
  - 已答对：彩色字形 + “会认”
  - 未学：灰底 + 小色点 + “待学”
- 底部 hint card：`下一颗星星 / 继续认识「上」/ 小气球升起来，停在上面。`
- 既给孩子点亮反馈，也直接把下一步任务说明白。

### P11 家长中心

- 进入前有家长验证弹层（小学算式 3+5=8）。
- 主屏分块：
  - 今日证据链：`5 个字有答对记录 / 下次建议从「上」开始，先找生活里的形状，再用手画一遍。`
  - 4 个统计 chip：`6 看过 / 5 画过 / 5 答对 / 5 会认`
  - 今日学习：`5 答对字 / 83% 正确率 / 24 分钟`（83% 来源就是我误点 `二` 那一题，没有被粉饰为 100%）
  - 识字回放：6 字 chips（含已 mastered 5 字 + 正在 看过 的 `shang`）
  - 可解释证据：`孩子能用气球上升的空间关系解释“上”` + `生活里发现 / 字形里确认 / 练习里答对` 三标签
  - 需要复习：`暂时没有需要复习的字`（之前 `三` 进过 needsReview，本轮已通过新一轮 P07 5/5 后清空）
  - 护眼节奏：`今天已用 24 分钟，建议先休息一会儿。`
- 这套证据链与 [[01-产品设计/Unit-01产品级重构执行规划|Unit-01 产品级重构执行规划]] 中“家长中心展示证据链，不是点过”的要求完全对齐。

## 未通过 / 仍欠缺

### dev server 根路径资源 404（开发环境 bug）

- `node src/clients/mobile-h5/server.mjs` 启动后，从 `http://127.0.0.1:4173/` 进入会让 `index.html` 加载，但相对路径 `./app.js` 解析为 `/app.js` → 404。
- 正确入口必须是 `http://127.0.0.1:4173/src/clients/mobile-h5/`。
- 后续修：`server.mjs` 的 `resolvePath` 应当让根路径重写后保留 `/src/clients/mobile-h5/` 前缀，或在 index.html 用绝对路径，避免开发环境踩坑。
- 不影响 VPS / Docker 部署，因为公网入口已经在 `/` 等价于 `/src/clients/mobile-h5/`。

### P08 庆祝页未触达

- 第 1 组 5/5 后 app 直接路由到下一组首字 P03，没有独立庆祝/解锁过场。
- 这是一个产品取舍：可以保持现状（节奏紧凑、不打断学习流），也可以补一帧庆祝以增强“一组通关”的仪式感。
- 当前知识库里的 P08 视觉稿仍存在，但运行时未被触发；后续如果决定补，需要明确触发条件（每组通关一次 / Unit-01 全通关时一次）。

### `一` 视频仍是 legacy-sample

- 与 [[2026-05-07-Mobile-H5产品级重构围栏与一字视频候选]] 一致，未变化：`legacyRecognitionVideo.status = "legacy-sample"`，`recognitionVideoFor()` 继续过滤；5.8s `yi-stage-official-candidate.*` 是 visual candidate，未接入主流程。
- 阻塞点仍是 baked audio 不能在当前沙箱生成。

### Phase 3 / Phase 5

- Phase 3 生图资产体系（视觉语法板 / 4 个分组场景底板 / 范式物件）尚未启动；当前 P03 / P05 用字形 SVG + carrier 文案承载，可用但不是正式插画。
- Phase 5 代表字 `二 / 三 / 人 / 山 / 火` 视频样片尚未做。

## 下一步建议（给下一个 session）

按优先级：

1. 解决 `一` 的 baked audio（沙箱外 `say` / 正式 TTS / 录音三选一），把 visual candidate 升为 official，跑 `npm run check:h5` 围栏，再接入 `recognitionVideo.status = "official"` 并提升资源版本。
2. 修 dev server 根路径资源 404：让 `server.mjs` 在 `/` 入口下也能正确加载相对资源。这条修完之后再考虑是否把入口改成 `/`。
3. 决策是否补 P08 庆祝过场。如果补，明确触发条件、动效预算、是否阻断式。
4. 启动 Phase 3 第一批生图：Unit-01 视觉语法板 + 4 组场景底板 + 范式物件。生图严格遵守 [[06-素材资源/Unit-01素材与生图生产规范|Unit-01 素材与生图生产规范]]：不画汉字、不画拼音、不画 UI 文案。
5. Phase 5 重做 `一` 标准样片，再做 `二 / 三 / 人 / 山 / 火`。
