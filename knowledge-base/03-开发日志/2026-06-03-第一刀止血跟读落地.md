## 1. 落地改动（4 文件，未 commit）

### 1.1 删假判分（核心止血 · 红线 §7.6）—— `Modules/FollowRecorder.swift`

**病灶**：旧 `scoreTier` 用包络 cosine 假装判「像不像」分三档（cos>0.6 great「很像，真棒！」/ >0.3 ok / else encourage）。真机暴露——**没出声/底噪时，`trimmedEnvelope` 归一后变平包络，与老师半正弦驼峰 cosine 天然偏高 > 0.6 → 判 great**。根因：不接 ASR 时包络 cosine 根本分不清「读对/瞎读/没读」。这是假纠音哄孩子，比"只放音"更糟（主动骗），踩穿红线 §7.6。

**修法（校准方案，不钟摆）**：机器只做它做得准的事。
- 删 `scoreTier` / `struct Score` 整套。
- 新增纯函数 `nonisolated static func detectVoice(rawPeak: Float) -> Bool { rawPeak >= voiceFloor }`，只判**有没有出声**——用归一**前**的 `rawPeak`（绝对能量），归一化会抹掉绝对音量（正是旧 cosine 误判的根源）。`voiceFloor = 0.05`（经验门限，⚠️真机真麦标定）。
- `trimmedEnvelope` / `envelope` 返回值从 `(env, dur)` 改 `(env, dur, rawPeak)`（rawPeak = 裁剪前全样本绝对峰值，本来就算了 `peak`，顺手带出）。
- `score(rawPeak:)` 三分支：出声→`tier="voiced"` + `passed=true` + 给星 + 引导对听；没出声→`tier="silent"` + `passed=false` + 温柔引导再说（不算错/不羞辱）；连续没出声 `silentStreak >= silentBailout(3)`→兜底 `passed=true` 放行（零挫败：卡关降难度保证过关）。
- 新增 `@Published var passed`（出声 or 兜底放行 → 顺序门可解、CTA 可达），取代旧的 `hasRecorded` 控制 CTA。`hasRecorded` 仍用于「听自己」按钮可用性。

### 1.2 录音单点化（问题二 · 调研§二1 幼龄禁持续按压）—— `FollowRecorder` + `P05a`

- 删「按住说话」全套：`holding` / `pressDown` / `pressUp` / `toggleRecord` / DragGesture。
- 改 `tapRecord()`（点一下开始、再点一下停）+ `autoStopTask`（`Task.sleep(maxRecordDuration=4.0s)` 到点没手动停也自动 `stop()`）。
- `P05a` 录音键从普通药丸改 **大圆钮**（`Button` + `ZStack`）：`Circle().trim(from:0,to:ring)` 倒计时环（`@State ring` 1→0，`onChange(of:recording)` 触发 `linear(duration: maxRecordDuration)` 动画），录音时 mic→stop 图标、金色→花瓣红。

### 1.3 光晕替丑手指（问题三 · 调研§二2）—— `DesignSystem/SharedComponents.swift`

- 新增 `PulseHalo`（`Circle().stroke` 向外 `scaleEffect 0.9→1.28` + `opacity 0.85→0` 扩散淡出，`repeatForever`，`allowsHitTesting(false)`）。录音大圆钮未录前外圈呼吸引导，替代 `TapHintHand` 的「丑手指」。
- `P05a` 的 `tierIcon`/`tierColor`：voiced→`star.fill` 金 / silent→`ear.fill` 天蓝（中性引导色，不用报错红）。反馈卡片从 `Capsule` 改 `RoundedRectangle` + 多行（新文案较长）。

### 1.4 A/B 对听（把"像不像"交还耳朵）—— `P05a`

- 操作区重排：大圆钮居中 + 下方「听老师 / 听自己」两个 `GhostCTA`。出声后（`passed`）显「点上面两个，听听你和老师哪里不一样」。

### 1.5 测试重写 —— `StarlightLiteracyTests/FollowScoreTests.swift`

- 从 cosine 三档打分改为出声检测：`trimmedEnvelope` 裁静音/归一/峰在中（解构改三元组）+ 报 rawPeak、`detectVoice` 门限、真出声样本判 voiced、**「没出声 rawPeak<门限 → 绝不误判出声」红线回归**、全静音兜底。
