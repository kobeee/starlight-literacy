# 2026-06-03 第二刀「音→形绑定」落地（认读页逐笔点亮）

> 承接 [[2026-06-03-第一刀止血跟读落地]]。护城河审计「四刀序」第二刀 = 调研标注「最有产品价值」的一刀，母题 B「两个『认』没练到字形」的**根**。

---

## 1. 为什么是这一刀

- 教学法第一性（[[../01-产品设计/幼龄儿童认字教学法重审与学字新流程]] §1）：3-6 岁孩子「音、义已有，缺的只是**形**」。
- 调研 §二3（Duolingo ABC）：朗读时被读内容同步高亮，把「听到的音」钉到「看到的形」上 = **音→形绑定**。
- 病灶：认读页 P03（主路径第 1 步「认读绑定」）字形是**静态 `Text(char.char)`**，念音与字形各自独立，没把孩子注意力从音牵到形。
- 06-02 看图认字改纯汉字候选只在「测」环节堵漏；本刀在「**教**」环节就把音钉到形上，更上游。

## 2. 落地改动（3 文件 + 1 测试，未 commit）

### 2.1 `Core/AudioService.swift` — `play` 回传时长
- `play(id:kind:)` 改 `@discardableResult -> TimeInterval?`，`return player?.duration`。现有 6 处调用忽略返回值即可（向后兼容）。认读页用它把逐笔节奏对齐念音长度。

### 2.2 `DesignSystem/SharedComponents.swift` — 新增 `StrokeRevealGlyph`
- 入参 `charId/hanzi/color/size/playToken/revealDuration`。`HanziData.load` 有数据 → `Canvas` 渲染：已点亮笔实色 `color.deep`、当前笔沿 median `trimmedPath(0→progress)` 描写（复用 `DemoWriterView` pattern）、未点亮笔 `Theme.lineSoft.opacity(0.22)` 极淡轮廓（silhouette 隐约可见不喧宾）；无数据 → 回退 `Text(hanzi)`（等于改造前）。
- `onAppear` 自动首演；`onChange(of: playToken)` 每次念音重演。Timer 0.03s 步进。
- 节奏护栏：`total = clamp(max(revealDuration, count*0.30), _, 3.0)`、`perStroke = max(total/count, 0.18)`——念音短不一闪而过、田 5 笔不拖沓。跑完停在整字成型实色。

### 2.3 `Screens/P03RecognizeView.swift` — 接线
- 删静态 `Text(char.char)` 块，换 `StrokeRevealGlyph(... size:168, playToken:revealToken, revealDuration:lastDuration)`。
- 新增 `@State revealToken/lastDuration`；`replay()` = 念音拿时长 → 存 `lastDuration` → `revealToken += 1`（念音 + 逐笔点亮同帧触发 = 音形同步）。scene 图 / 喇叭脉冲 / pinyin / CTA / `.onAppear` 不动。

### 2.4 `StarlightLiteracyTests/StrokeDataTests.swift`（新文件，需 xcodegen）
- 断言 Unit-01 全 20 字 `HanziData.load` 非空 + `strokes.count == medians.count`。逐笔点亮强依赖 json，缺一个就静默回退静态字、丢本刀价值且不报错，用测试钉死。
