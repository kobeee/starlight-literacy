## 🔴 问题一（严重·踩红线）：没出声也判「很像，真棒！」= 假纠音

- **现象（用户真机）**：跟读时**根本没发出任何声音**，打分仍显示 **great 档「很像，真棒！」**。用户原话：「啥声音都没发出……就提示『很像，真棒！』，真 tm 哄小孩呢是吧」。
- **为什么是严重问题**：直接踩穿红线 #6（[[../01-产品设计/竞品洪恩用户反馈校准]] §7.6）——**跟读纠音必须真做、不能只放音哄孩子**。「没读也夸」比「只放音」更糟，是主动欺骗，正是洪恩被骂、我们立项要反的东西。也是 [[../03-开发日志/2026-05-31-iOS真机B5听声与布局safeAreaInset根治|bug#2]] 的反向翻车：当时治「读对了却一直『再试一次』」，这次是「没读却『真棒』」。
- **根因怀疑（待新 session 查证，不写死）**：打分 = 包络 cosine（`FollowRecorder.scoreTier`，`cos>0.6` → great「很像，真棒！」/ `>0.3` → ok / else encourage）。**没出声 → 录到静音 → `trimmedEnvelope` 掐头去尾 + 归一后很可能变成一条「平包络」；平包络与老师的半正弦驼峰 cosine 天然偏高（`FollowScoreTests` 当时就记过这条），轻松 `>0.6` → 误判 great**。bug#2 修复用的是**合成包络单测**、没有真麦克风的静音录音，所以盖住了这个盲区——模拟器无麦，只有真机能暴露。
- **更深一层（产品级矛盾，归知识库）**：不接 ASR 时，包络「形状」cosine **根本分不清「读对 / 瞎读 / 没读」**。于是「零挫败（永远给星不羞辱）」和「真纠音（不能哄）」两条红线在「不接 ASR」前提下正面冲突。详见 [[../01-产品设计/跟读真纠音与零挫败的矛盾]]。**这是新 session 要讨论的核心题，不是改个阈值能了的。**

## 🟡 问题二（交互）：「按住说话」5 岁孩子不懂，可能只点一下

- **现象（用户）**：本 session 把录音键从点按改成「按住说话」（按下录·松手停）。用户指出：**5 岁孩子不懂「按住」，他可能就点一下** → 点一下 = pressDown/pressUp 瞬发、`holding` 守门下不真正录音 → 啥也没录。
- **性质**：A 去文字化方向对，但「按住」这个手势对 3-6 岁的可达性存疑。要重新想录音的触发方式（点一下开始录、到时/再点停？带倒计时？长按 vs 点按怎么对幼龄最稳），和问题一一起在新 session 定。

## 🟡 问题三（视觉）：跳动手指引导有点丑

- **现象（用户）**：本 session 给 CTA / 首页 / 跟读键加的 `TapHintHand`（`hand.tap.fill` 上下 bob）**有点丑**。
- **性质**：去文字化「视觉自驱信号」方向对（红线禁操作语音、只能视觉），但 SF Symbol 手指 + 生硬 bob 不够好看 / 不够「田园暖彩」。要换更贴风格的引导形态（光晕脉冲？更可爱的插画手 / 小动物指引？描边箭头？）。
