## 1. 落成内容

`Resources/Hanzi/` 已打包 Unit-01 全 20 字的 hanzi-writer-data JSON（strokes + medians）。

### 1.2 护城河 #1 · 写字真判定（红线 §7.4）

- `Modules/HanziStroke.swift` 的 `StrokeJudge.judge(user:median:size:)`：对每一笔做几何判定 —— too-short-length / reversed / bad-start / bad-end / off-track 五类拒绝，按到中线折线的**平均**距离判定（单点抖动不冤枉孩子）。
- `WritingSession`：错 3 次显示提示，错 5 次当前笔**自动放过**并记入 `autoPassed`（零挫败降级，视觉用浅色）。
- **不是"乱画也判对"**：点一下（两点重合）→ too-short-length；反向描 → reversed；整笔鼓成大弧偏离中线 → off-track。

### 1.3 护城河 #2 · 跟读纠音（红线 §7.6）

- `Modules/FollowRecorder.swift`：AVAudioRecorder 录音 → 包络 → 启发式三档评分，**不接 ASR**（与方案一致），全程本机、不上传。
- `Info.plist` 麦克风用途文案明确"只在本机和老师声音做波形对比，不上传"。

### 1.4 顺序门是系统边界，不是 UI 表演

`Core/AppModel.swift` 每字"写→跟读→认"逐门解锁：
- `markFollowed` 守 `writtenIDs.contains(id)`（没写完不能记跟读）
- `markPassed` 守 `followedIDs.contains(id)`（没跟读不能过图卡），星数取 `max`（重学不降星）
- 用**每字独立的 Set**，不是一个全局布尔 —— 绕过 UI 直接调模型也跳不了步。

### 1.5 商业链路（红线 §7.1 §7.2 §7.5 §7.9）

`Data/Commerce.swift`：三档（免费 Unit-01 / ¥9.9 单元单买 / ¥199 一期买断）+ 退款 ≤2 步可达 + 邀请奖励只给内容权益（单元解锁 / 学伴券）上限 10、仅家长中心可见，禁现金/禁课程券/禁可流通积分。

## 4.3 解决"MobAI tap 驱动没连上"——改用 idb 直驱模拟器（2026-05-29 续）

§2.3 的诚实边界（MobAI tap 驱动没连上、走不通 skill 真 tap 金流程）**已找到干净解法**。

### 排查结论：别修 MobAI，绕开它

- MobAI 进程在跑，监听两个端口：**8686**(MJPEG 录屏桥) + **8787**(Web 控制台)。
- 8787 不是简单本地 REST——响应头有 `Cf-Cache-Status: DYNAMIC` / `Alt-Svc: h3`，是 **Cloudflare 套出来的云端控制台**，设备自动化走"云 ↔ 本地 companion"。
- 它的 MCP 工具 `execute_dsl/test_run/observe` **根本没注册进 Claude Code 会话**（ToolSearch 搜不到，grep 命中的全是历史 transcript）。
- 结论：靠 MobAI 就得搞通云端 MCP 集成，不可控。**改走 idb 本地直驱**。

### idb 路径（本地 / 无云 / 无 MCP，已实测打通）

- `idb_companion` 本来就装着（`/usr/local/bin/idb_companion` 1.1.8）。
- `fb-idb` python 客户端用 `python3 -m pip install --user fb-idb` 装好，命令在 `~/.local/bin/idb`（用前 `export PATH="$HOME/.local/bin:$PATH"`）。
- 模拟器：iPhone 17 / iOS 26.3 / UDID `7E26ACDC-3E86-4205-983B-DF44FF75717B` / 屏幕 **1206×2622 px（402×874 pt，density 3.0）**。
- 实测三连通过：`idb connect <udid>` → `idb describe` → `idb screenshot` 出真帧（1206×2622 RGBA）。

常用命令：

```bash
export PATH="$HOME/.local/bin:$PATH"
UDID=7E26ACDC-3E86-4205-983B-DF44FF75717B
idb connect $UDID
idb ui tap   <x> <y> --duration <s>            # 坐标单位见下方坑
idb ui swipe <xs> <ys> <xe> <ye> --duration <s> --delta <px>   # delta=触点间距→生成多触点连续线
idb screenshot --udid $UDID out.png
```

### 能解锁什么（按价值）

1. **G5 手感实测（最高价值）**：`idb ui swipe --delta` 能真在 P04 田字格里拖手指描"一"（水平直笔），亲眼验 `StrokeJudge` 判过/判挫、±容差松紧。补上 §4.1 G5"从没真用手指描过"的洞。
2. **真 tap 驱动 demo**：替代 §2.3 的 auto-tour 兜底；录屏仍用 :8686 MJPEG 桥或 `xcrun simctl io booted recordVideo`。

### 两个诚实边界（不吹）

- **idb CLI 的 swipe 只能直线 A→B**。"一"是直笔能完整验证；其余 19 字多为多段/带弯笔画，CLI 线性 swipe 写不出——要么直接调 idb 的 gRPC HID 流式接口逐点喂，要么点对点拼。**"一"跑通全链路，复杂字需额外管线**。
- **mobile-recorder skill 硬绑 MobAI 的 `.mob`/test_run**，没法原样跑；它那套 explore→record→timeline 管线可用 idb + ffmpeg 复刻。
- **坐标单位待下个 session 首跑校准**：idb 的 tap/swipe 坐标是 pt 还是 px 需第一枪用 screenshot 比对确认（截图是 px=1206×2622，逻辑是 pt=402×874），别凭假设乱点。

### Codex 新增发现（Claude 笔记未覆盖）

1. **P05a 跟读页的"录我的"真实交互异常。**

2. **麦克风拒权路径与页面文案冲突，会卡死顺序门。**
   - `FollowRecorder.requestAndStart()` 在拒权时只设置 `permissionDenied = true`，没有进入 `phase = .scored`，也没有生成示意 `userEnv`。

3. **学习进度只在内存，不持久化；进程重启会丢顺序门状态。**
   - `AppModel` 里的 `writtenIDs` / `followedIDs` / `passedIDs` / `starsByChar` 都是内存 `@Published` 集合。
   - 当前只有 `Commerce` 走 `UserDefaults` 保存；学习进度没保存。
   - 这能解释 P05a 异常后回到 P04 且写字完成状态丢失。就算不是根因，作为儿童学习产品也必须补，否则杀进程/系统回收后会丢学习链路。
